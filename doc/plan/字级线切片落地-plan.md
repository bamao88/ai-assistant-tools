> 读者 = 产品经理。这份文档先讲**背景与来龙去脉**，再讲**做什么、怎么验收**。轻技术。
> 这是 videocut-zh 集成的**第二期**。第一期见 `doc/plan/videocut-zh-integration-plan.md`。
> 状态：**已拍板 · 待执行**。日期：2026-06-16。

## 一、背景：这件事从哪来

### 1）我们有两条剪辑线，这次动的是「字级线」

视频切片有两条并存的路线，区别在于「切多细」：

| | 句级线（线上老路） | 字级线（这次的主角） |
|---|---|---|
| 最小单位 | 整句 | 单个字（毫秒级时间戳） |
| 来源 | 腾讯会议转录 | 火山字级转写 |
| 能不能删句子中间的口水 | **不能**（只能整句留/弃） | **能**（精准抠掉「嗯/啊/那个那个」） |
| 适合 | 简单稳，已在线上出片 | 做「干净口播切片」必须的精度 |

字级线的**地基**（火山字级转写）在第一期 WS-2 已经建好。

### 2）字级线现在到哪了：能出「文案」，出不了「视频」

到目前为止，字级线端到端能跑出**切片文案**：

```
火山转录 → 自动选片 → 去口水 → 每条切片的干净文案
```

而且实测过质量（用 videocut-zh 的真实素材）：
- **选片**：我们自动选出的 top 选题，和 videocut-zh 人工选的高度重合——选片判断力到位。
- **去口水**：把「真的真的真的→真的」、ASR 错字（低发→低代码）清干净，关键的**承接句也保住了**——文案质量好。

**但它止于文字**。你看到的是一段段干净文案，**看不到真正的视频切片**。要验收「这套流程到底行不行」，必须把视频**真的切出来**看。

### 3）这一期只干一件事：把视频实际切出来

把字级线从「出文案」推进到「**从源视频切出每条去口水后的干净口播片段**」。

## 三、目标链路：丢一个长视频进去，出一批干净切片

```
源视频 + 火山字级转录
  → ① 自动分句        把字级词按停顿切成句（让转写自给自足，不再借外部文件）
  → ② 精选选片        现成流程：选出哪几条切片 + 每条用哪些句
  → ③ 字级去口水      AI 按规则定「删哪些字」(语气词/卡顿/重复/残句)，🚨承接句保护
  → ④ 删词→保留区间   删完保留的字 → 合并成保留时间区间
  → ⑤ 边界吸停顿      切点吸到最近的字间停顿，更自然
  → ⑥ 从源视频切      ffmpeg 切出每条 clip.mp4（去口水后干净片段）+ 字幕 + 文案
```

## 四、要补的四处缺口（每处都搬 videocut-zh 的对应代码）

| 缺口 | 现状 | 怎么补 |
|---|---|---|
| **①自动分句** | 我们转写只产字级词、不自动分句，现在借 videocut-zh 的文件 | 搬它的「按停顿（≥0.5秒静音）切句」逻辑，转写自给自足 |
| **②去口水到字** | 去口水现在只到文案级（改文本），没落到时间轴 | AI 把选段逐字编号读，返回「要删哪些字」，删的是口水字的时间 |
| **③去口水回写时间轴** | —— | 删词后保留的字 → 合并成保留时间区间（这就是精确切点） |
| **④切点吸停顿** | 字级吸附代码建好了但没接进流程 | 接上：切点吸到字间停顿中点，听感更自然 |
| **（新增）切视频** | 字级线从没真正切过视频 | 搬 videocut-zh 的切片代码：保留区间 + 源视频 → 切出 clip.mp4 |

## 五、几个设计要点（产品要知道的）

- **去口水删字 ≠ 改声音**：删的是口水词那段（音频跟着删，形成跳切）；术语纠错（低发→低代码）只改**字幕文字**，不动声音、不动切点——和 videocut-zh 一致。
- **承接句保护**贯穿到字级去口水：四类高危承接句（设问引子/对比转折/解释概念/数据前铺垫）AI 不许删。
- **产物落点**：切片存 `var/<账号>/cuts/<视频名>/`（运行时目录，不进 git）。⚠️ 该目录可能被清理，**跑完想留就拷到目录外**。

---

## 六、怎么算做成了（验收）

1. **分句**：自动分句结果和 videocut-zh 的分句高度一致。
2. **去口水**：选段删字后，保留文案没了语气词/卡顿、承接句在；保留时长 < 原段时长。
3. **切视频（主验收）**：跑端到端，从源视频切出**精选 top 3~5 条** clip.mp4，人工看四点：
   - ① 选对了段；② 口水/卡顿在视频里被跳切掉；③ 片子顺、承接句没断；④ 字幕文案干净（术语纠对）。

---

## 七、风险 / 注意

- **AI 数索引可能出错**：字级删词靠 AI 返回字的编号区间，可能数错——加校验（非法区间丢弃）+ 保底（实在不行只删整段、不删字内）。
- **跳切听感**：删句子中间的单字会产生跳切，靠留白参数控制；过碎时以「语义完整短句」为最小删除单位（规则已写）。
- **源视频大（4.9G/3.3h）**：只读源、精切不整体转码，逐条切。
- **量大选片**：本期不做，记为后续（纯方法学，需另实现多路并读+去重）。
