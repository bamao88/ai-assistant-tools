## 〇、一句话目标

火山转录里**本来就带**标点、句界、书面数字（"90%"），但目前在"去口水"和"出片"两步被丢成了裸字。这份计划把这份原生信息**一路带到底**，让成品字幕、文案、以及喂给 AI 生成 PPT 的输入，都是**带标点、带"90%"、按语义断好的句子**。

---

## 一、先厘清：火山给的是"一个文件、两层数据"（不是两个文件）

火山转录回来，我们解析成**一个文件** `words.json`，里面有**两层**：

| 层 | 字段 | 里面有什么 | 大白话 |
|---|---|---|---|
| **句层** | `sentences[]` | 火山按**语义**切好的整句，**带标点**、数字是 **"90%"**，每句带起止时间戳 | 一整句话，标点、阿拉伯数字、句子边界都在这层（火山的识别优化都在这） |
| **字层** | `words[]` | 一个一个字，每个字只带时间戳，**无标点**、数字是原始的"百分之九十" | 拆成单字 + 时间，专门用来对齐到视频的精确秒数 |

> 大白话：**句层负责"内容好不好读"（标点、语义、书面数字），字层负责"切到视频哪一秒"（精确时间）。** 这次的核心就是——内容用句层，时间用字层，两层各司其职、最后合起来。

这一层已经做好了（上一轮 `backends.py` 已经把 `sentences[]` 收下来存进 `words.json`）。

## 二、完整切片流程：4 步，每步「输入 → 输出」

```
         输入                          这一步做什么                      输出
┌──────────────────────────────────────────────────────────────────────────────┐
│ 步骤1  火山转录                                                                 │
│   IN : 源视频 + 火山 API                                                        │
│   OUT: words.json = { 字层 words[](带时间) , 句层 sentences[](带标点/ITN/句时间) }│
├──────────────────────────────────────────────────────────────────────────────┤
│ 步骤2  选题 + 定边界                                                            │
│   IN : 句层 sentences[]（语义句，句界准）                                        │
│   DO : AI 选出值得剪的选题，定出每条选题覆盖哪几句（keep_sids）                  │
│   OUT: 每条 clip = { 标题/钩子 , keep_sids(句号区间) , 句级时间段 }              │
├──────────────────────────────────────────────────────────────────────────────┤
│ 步骤3  去口水  ★本次改动①                                                      │
│   IN : 该 clip 覆盖句子的【句层带标点 ITN 文本】（不再是字级裸拼）               │
│   DO : AI 通读、只删不改地删掉口水（嗯/那个/重复/残句），保护承接句             │
│   OUT: ① 删口水后的【带标点 ITN 文案文本】（AI 直接吐出）                        │
│        ② 把这段文本对齐回字层 → 拿到保留内容的精确时间(keep_spans)  ★本次改动②  │
├──────────────────────────────────────────────────────────────────────────────┤
│ 步骤4  出片                                                                     │
│   IN : 步骤3 的【带标点文本】 + 【保留时间段】                                   │
│   OUT: clip.mp4（按时间段切）                                                    │
│        clip.srt（字幕，带标点 ITN）  ──┐                                         │
│        clip.txt（文案，带标点 ITN）    │                                         │
│        PPT/框架页 pages（读 clip.srt）─┘ 字幕修好，PPT 输入自动也带标点          │
└──────────────────────────────────────────────────────────────────────────────┘
```

## 三、这次到底改什么（两个改动点，对应步骤3）

### 改动① 去口水的"输入"从字级裸拼升级成句级带标点
- **现状**：喂给去口水 AI 的是字一个个拼起来的裸文本（"我们增长了百分之九十嗯那个效率翻了五倍"），无标点、数字没书面化。
- **改后**：喂句层带标点 ITN 文本（"我们增长了90%，嗯那个效率翻了5倍。"）。
- **好处**：AI 看得到标点和句界，判断"哪是口水、哪是不能删的承接句"更准；而且 AI **只删不改**地删完，吐出来的**就是带标点的成品文案**。

### 改动② 把去口水后的带标点文本"对齐回字层"拿精确时间
- **为什么还要对齐**：步骤4 切视频、做字幕都要**精确到秒**，而精确时间只在字层。所以要把"AI 删口水后的带标点文本"和字层逐字对回去，给每段文字配上时间。
- **唯一的难点 = 书面数字块**：文本里的 "90%" 在字层是"百分之九十"5 个字、3 个字符，对不上号。所以对齐时把 "90%" 当成**一个整块**，绑定字层"百分之九十"那 5 个字的时间（起=百、止=十）。**整块要么留要么删，绝不切成"90"。**
- 标点（，。？）字层没有，挂在它前面那个字/块上，前面留它就留、前面删它就删。

> 大白话：AI 给的是"读起来对的文字"，字层给的是"时间对的字"。改动②就是把这两样**逐字捏在一起**，配出"既带标点、又知道每段在视频第几秒"的成品。数字"90%"是唯一要特殊照顾的——把它当一个不可拆的积木。

## 五、降级边界（保证不断流，任何一步出问题退回今天的可用状态）

| 情况 | 行为 |
|---|---|
| 火山没返回句层（旧文件/换转写源） | 没有 `sentences[]` → 去口水退回字级裸拼输入、字幕/文案退回字级裸拼，**和今天完全一致** |
| 某段文本对齐不回字层（数字块对不齐等） | **只这一段**退回字级裸拼 + 打日志，其余正常带标点 |
| 去口水已有的"保留<50%就整段不删"保底（`script_clean.py:161`） | 继续生效，对齐在它之后 |
