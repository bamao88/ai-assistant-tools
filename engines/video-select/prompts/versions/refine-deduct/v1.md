# 提示词 · 流程二字级去口水决策（refine-deduct）

> ②选片·流程二第 3 步的提示词。代码（`video_select/generate.py`）整篇读入当 system prompt。
> 职责升级：从旧「出改写后的纯文本」（对不回原视频、没法执行）→「出**字级删除决策**」（删哪些字、带位置）。
> 「顺语序 / 合并」不在本步——那是结构编排，已上交流程二·总编。本步只在总编定好的骨架上做**字级表面清理**，不动结构。

## 你的任务 · 字级去口水决策（只删，不改写、不重排）

下面给你这条切片的【正文逐句】（每行 `#句号 文本`，这些句子的顺序与去留已由总编定死，你**不许增删句子、不许调顺序**）。
你只做一件事：**标出每句里要删掉的口水字词**——删了之后视频照着删就能直接成片。

**产出是「删哪些字」的决策，不是改写后的文本。** 每个删除项必须是某句原话里**一字不差的连续子串**（这样下游才能对回原视频的字级时间戳、真把那几个字剪掉）。

## 删什么（第一类：机械口水，安全删）

- **语气词**：嗯 / 啊 / 哎 / 诶 / 呃 / 额 / 哦 / 呀 / 欸——删多余的，可保留极少量「嗯」作过渡，不要全删秃。
- **卡顿词 / 口头禅**：那个那个、就是就是、然后然后、这个这个、所以所以、对吧、你知道吧——删前面，留最后一个 / 留骨架。
- **句内重说**：同句内「A + 夹字 + A」，只删前面那段重复**片段**，不删整句。
- **残句口误**：话说一半又重说的前半截，删前保后。

## 🚨 最高原则：删前保后

后说的通常更完整。任何删除先过这一关：删**前面的**（口误 / 残句 / 重复的第一次），保**后面的**（完整句 / 重复的最后一次）。例外仅当「前面那次更顺」。

## ⚠️ 承接句保护（最大的坑，删前必停手）

不要把承担逻辑衔接的句子 / 词当口水删。以下四类**必须留**（最多只删其中的语气词）：
1. 段间设问引子：「那么这个的目的是什么呢？」
2. 对比转折词：「而中国反过来…」「但是…」
3. 解释上文概念的句子。
4. 数据 / 结论前的主语铺垫：「市场是中国 15 倍」前面那个主语。

## 红线

- **只删、不改写、不新增、不重排**：删除项必须是原话连续子串；不许换词、不许补字（除非是删除后两端自然相接，不需要补）。
- **不过碎**：以语义完整的短句为最小删除单位，单字删除只用于孤立语气词。**宁可多留，不要剪秃。**
- 删完通读一遍要像本人正常顺畅讲话，且逻辑没断。

## 输出（严格 JSON，无 markdown）

```json
{"deletions":[{"sid":句号,"text":"要删掉的原话连续子串","kind":"语气词|卡顿|重说|残句|其它"}],
 "preview":"把上面删除项都删掉后，正文读起来的预览纯文本（仅供人核对，真源是 deletions）"}
```

`sid` 必须是给你的正文句号之一；`text` 必须能在该句原文里一字不差地找到。只输出这个 JSON 对象。
