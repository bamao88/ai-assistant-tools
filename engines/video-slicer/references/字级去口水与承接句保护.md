# 字级去口水与承接句保护（字级剪辑线·判断知识）

> 来源：videocut-zh `03_去口水与逻辑准则` + `去口水规则细则/`，沉淀为我们**字级剪辑线（方案B / cut_word）**的判断知识。
> 用途：字级剪辑在字级时间戳上**真删字/删句**时的决策依据。WS-2 的 cut_word 去口水步骤直接把本文档作为 system prompt 基底。
> 与 `srt_fix` 的区别：`srt_fix` 是 **1:1 不删条**的字幕校对（保时间轴）；本文档是**会改变时间轴的删除决策**，只属于字级线，不属于 srt_fix / 句级线。

机械去口水谁都会，难的是「去完还像人正常说话、且逻辑没断」。所以分两类删除，第二类是高危区。

---

## 🚨 最高原则：删前保后（优先于一切子规则）

后说的通常更完整。任何删除先过这一关：
- 删**前面的**（口误 / 残句 / 重复的第一次）
- 保**后面的**（完整句 / 重复的最后一次）

例：「于是很把于是很容易把它理解成…」→ 只删「于是很把」，保留「于是很容易把它理解成…」。
**句内重复只删重复片段，不删整句。**

例外：仅当「前面那次更顺」时才删后保前；除此一律删前保后。

---

## 第一类：机械口水（安全删）

| 类型 | 规则 | 删除策略 |
|---|---|---|
| **语气词** | 嗯/啊/哎/诶/呃/额/唉/哦/噢/呀/欸 | 删多余的，**保留适量「嗯」作过渡**，不要全删 |
| **连续语气词** | 嗯啊、啊呃、哦嗯… | 全删 |
| **卡顿词** | 那个那个、就是就是、然后然后、这个这个、所以所以 | 删前面，保留最后一个 |
| **句间重复** | 相邻/隔一句开头雷同 ≥5 字 | 删**前句整句**（≥3 次重复则只留最后完整的） |
| **句内重复** | 同句内 A+夹字+A | 只删前面的重复**片段**，不删整句 |
| **残句** | 话说一半被打断、后面重说 | 删**残句整句**（从句首到句尾，不只删异常结尾），保留后面完整版 |
| **脏字 / 平台屏蔽词** | — | 删 |
| **长静音** | >1s 压到 ~0.3s；0.2–1s 句间卡顿预删；≤0.2s 自然停顿保留 | 整段标记，不拆分；开头静音必删 |

**语气词删除边界**：删的是「前一个字的 end → 后一个字的 start」，别连前字尾音一起删。

---

## 第二类：逻辑承接句（看着啰嗦，实则不能删）⚠️ 最大的坑

去口水去过狠，会把「承担逻辑衔接功能的句子」当口水删掉，导致段落间逻辑断裂、零背景观众听不懂。
**第二类必须留**（可只去其中的语气词、留骨架）。

**四种高危承接句，删前必停手判断：**

| 类型 | 例子 | 删了的后果 |
|---|---|---|
| 段间设问引子 | 「那么我想说，这个的目的是什么呢？」 | 下一段凭空冒出 |
| 对比转折词 | 「而中国就反过来…」「但是…」 | 「A 向前 / B 往回」退化成平铺并列 |
| 解释上文概念 | 上句「利用这个机会」→ 下句「美国领先反而是机会」 | 概念悬空 |
| 数据/结论前的主语铺垫 | 「美国整个在企业服务」→「市场是中国 15 倍」 | 「15 倍」指代不清，伤核心卖点 |

---

## 跨段拼接：必加自然引入

- 每段开头不能从上段硬切到新主题。
- 从长分享/直播截取的成片，原录音多是「直入式」开头、缺钩子 → 开头补一张**点题卡**（大标题疑问钩子 + 预告各段维度）。
- 拼接处留 0.1–0.3s 自然停顿，别贴死。

## 精细度红线：不过碎

剪完读一遍要像「本人正常顺畅讲话」，不是逐字拼接的机器音。
- 以**语义完整的短句**为最小删除单位，单字删除只用于孤立语气词。
- **宁可多留一点，也不要剪秃。**

---

## 验收：站在「零背景观众」视角通读

把清洗稿当成给一个完全没听过这场分享的人看，逐项查：
1. **段间转折**是否自然（有没有凭空冒出新话题）？
2. **每段开头**有没有自然引入？
3. **关键数据/结论**有没有主语（「15 倍 / 3 步」是「什么」的）？

任一项不通 → 回原录音找回被误删的**承接句、原声补回**（不重新配音、不编造）。字级时间戳让你能精确定位到那一句的时间区间。
**验收不只是查「还有没有口水」，更是查「逻辑断没断」。**
