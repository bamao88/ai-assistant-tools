# 配图设计知识库

> 给内容 Agent 用的"审美与排版"知识。配图丑，不是 AI 不会画，而是**版式没做对**。
> 这份文档讲清楚"为什么好看"，配合 `templates/` 里的模板使用。

## 0. 核心理念：锁死设计，只改内容

以前每次让 AI 从零设计配图（或用 excalidraw / mermaid 自动出图），质量飘忽——这是丑的根源。
正确做法：**模板里的 CSS 是经过调校的设计系统，不要动；你只改 `<!-- EDIT -->` 标注的文字/数据。**

这样配图的"下限"被模板抬住，你专注把内容填好即可。

## 1. 六条版式铁律

1. **字体层级要拉开**。标题与正文字号差距要大（≥2 倍）。模板已经做好，别把标题改小。
2. **大胆留白**。宁可少放内容，也不要塞满。空白是高级感的来源。一张图只讲一件事。
3. **配色克制**。一个主色（accent）+ 中性灰阶就够。模板用 `:root` 变量统一管理，不要在内容里硬写颜色。
4. **对齐与节奏**。左对齐为主，元素成组、间距统一。模板用 flex/gap 保证，别加内联 `style` 破坏。
5. **强调要少而准**。每张图最多高亮 1 个关键词（模板里的 `.hl`/`<em>`/`.em`）。全部加粗 = 没有重点。
6. **风格一致**。同一篇文章的多张配图用同一套风格预设（见 §3），形成系列感。

## 2. 什么场景用什么模板

| 模板 | 用途 | 尺寸 | 选它的信号 |
|------|------|------|-----------|
| `cover-*` | 文章封面/首图 | 1600×900 (16:9) | 每篇文章必有，放标题 |
| `diagram-flow` | 架构图/流程图/关系图 | 1600×1000 | 文中讲"由几部分组成""分几步" |
| `quote-card` | 金句卡 | 1080×1350 (4:5) | 有一句话很有传播力，单独成图 |
| `data-card` | 数据/清单/对比 | 1080×1350 | 有数字、要点、前后对比 |

**X(Twitter) 实战**：封面 1 张 + 金句/数据卡 2-3 张组成多图推文，效果最好。竖版 4:5 在信息流里占屏更大。

## 3. 三种风格预设（与封面一一对应）

| 预设 | 气质 | 适合 |
|------|------|------|
| **极简科技（深色）** | 克制、高级、技术感 | 深度技术、硬核内容（默认） |
| **明亮渐变（玻璃）** | 活泼、吸睛、年轻 | 涨粉向、轻量科普 |
| **编辑杂志（浅色）** | 专业、有栏目感 | 系列内容、专业人设 |

- 封面：三种是**独立版式文件**（`cover-minimal/gradient/editorial.html`），直接选用。
- 概念图/金句/数据卡：在文件顶部的 `:root` 注释里写好了三套调色板，**换风格 = 替换那一组 `:root` 值**（注释里已给出"渐变亮""编辑浅"的现成数值）。
- **一篇文章只选一种风格**，所有配图统一。

## 4. 字体（macOS 本机已装，无需联网）

- 中文正文/标题：`"PingFang SC"`（苹方）——干净现代，是高级感的基础。模板已设好。
- 等宽/代码/编号：`"SF Mono", ui-monospace, monospace`。
- **不要**引入网络字体（渲染时不联网，会 fallback 成丑字体）。

## 5. 文案长度控制（很关键）

文字太长会撑破版式。每个 `EDIT` 位置遵守：

- 封面主标题：2-3 行，每行 ≤9 字最稳；太长就精简，不要靠缩小字号。
- 小标签/分类：8-14 字。
- 副标题：一句话，≤30 字。
- 金句：1-3 句。
- 数据卡：3-4 条；`.num` 尽量短（`7×24`、`2`、`0`、`98%`）。
- 流程节点：3-4 个；每个标题 ≤6 字，说明 ≤12 字。

填完先渲染看一眼，**文字溢出/换行难看就删字**，不要改 CSS 字号。

## 6. 常见"翻车"原因（照着避坑）

- ❌ 在内容里硬写颜色/字号的内联 `style` → 破坏设计系统。只改文字。
- ❌ 标题塞太多字、什么都想说 → 一张图只讲一件事。
- ❌ 一篇文章每张图风格不一 → 统一用一种预设。
- ❌ emoji 滥用 → 概念图/数据卡每个节点最多 1 个，封面 0-1 个。
- ❌ 用 excalidraw / mermaid / 手绘风做正式配图 → 那是草图风，正式配图要的是版式设计。
- ❌ 改了 `--accent` 但忘了 `cover-editorial` 里 `h1 u` 的 `box-shadow` rgba（那处是写死的高亮底色，换主色要同步）。

## 7. 渲染

```bash
tools/illustration/render.sh <你的.html> [输出.png]
```
用本机 Chrome 无头截图，输出 @2x 高清 PNG。尺寸由模板里的 `<meta name="render-size">` 决定，不用管。
