# 猫猫电视机内容素材包

本目录是本项目**封面、标题、正文、关键词及其检查规则的唯一维护位置**。`SKILL.md` 管任务范围和执行顺序，详细规则在同目录的参考文件，项目检查实现在 `scripts/`。旧项目文档和旧专属 Skill 仅供迁移定位，不能再提供另一套现行指令。

## 先确定任务范围

- 完整视频素材包：交付所需数量的新增成片、实际封面、平台标题、分段正文、独立关键词、来源资料、目标平台文件、审阅页和 ZIP。缺项或用旧片凑数不能算完成。
- 只改封面、标题、正文或关键词：读取对应章节，完成该项并同步受影响的 item/导出；不强制重做视频或整批生产。
- 按内容目的选封面：直接供猫看／玩的节目走 [节目封面](references/cover.md)；给人读知识、变化或进展的笔记走 [内容型笔记封面](references/note-cover.md)。不能只凭画面里出现老鼠、节目截图或“游戏”二字分流。

用户已授权制作到本地待审包时，常规选材、草稿与派生文件沿已有授权继续。已确认内容默认保留；用户要求调整时同步改受影响产物，不逐级重复询问。素材例外、关键事实缺失及对外动作仍按真实权限处理。

## 完整视频包的执行顺序

1. **查重后选新来源。** 用本目录 [content_package.py](scripts/content_package.py) 的 `audit` 跨平台核对已发布、已提交定时、已有平台稿件、其它在制及本批重复。沿原链接／视频 ID、素材关联、源文件和成片哈希追溯；换 item ID、标题、封面或切片时间码不构成新增。新批次默认排除已使用原视频，长片确有独立未用场景时先留场景对照和本次明确使用决定；跨平台补发不计新增。定时到期不能自行升级为已公开。
2. **登记来源并冻结连续片段。** 默认海外 YouTube 外部视频；其它来源、完整原片或产品素材按项目具体授权处理，旧例外不推广。登记真实作者、原链接、使用依据及权利状态，负责人同意不等于原作者商业授权已核验。实际审看对象、动作、背景、首尾与声音，选择能独立成立的一段；核对开头能否辨认标题所指对象及其后是否持续可见，不因封面有对象就认为片头成立，也不把一次修改固化为固定秒数。不拼场景或循环凑片，不移除作者标识，不固定截成30秒。合集先按对象／背景／镜头／声音变化建立场景时间索引；排除密集字幕、闪烁、爆音、场景切换、无关人物或过度杂乱候选。获取遇人机验证时停止该方式并保留缺口，不循环试探或绕过。
3. **建立 item 与成片。** 候选通过初检才分配 topic/item ID。复用通用剪辑，保存源片和成片哈希、原片时间基准、连续起止、编码／尺寸／时长及实际检查。数量不足可先推进已合格条目，继续寻找缺口，不以旧内容填满数量。
4. **完成封面和全部文案字段。** 正文含结尾互动段 `body_cta`，另写置顶评论和策略标签（见 copy.md「互动钩子」）；成片按 overlay.md 叠加顶部给猫看的提示字。 按 cover 制作封面实图与文字，按 copy 生成平台标题、所选正文类型、关键词及独立来源资料。知识正文也必须完成账号关键词；不能因交给通用写作工具就漏掉话题。
5. **检查、导出、写回。** 按 execution 运行本目录检查器、既有导出与解析工具，逐项核对实际媒体和解析字段。按 `DATA.md` 更新作品／选题／素材，不创建 publication，不把本地 `draft` 当成平台草稿。
6. **交付可审阅产物。** 重新查重后生成可解压审阅的本地包。每条同时展示视频、实际封面、封面名／频道、平台标题、分段正文、独立话题、来源和检查范围。历史版本保留，旧包被撤回后退出有效交付入口。

## 验收边界

完整解码、抽帧和峰值不能替代全片原速有声审看；字段检查不能替代封面实图、缩略图和系列审查。按实际证据区分 `logic/contract`、真实文件 replay、本地 visual QA、平台 E2E 和负责人接受，未完成的层级明确列出。`ready` 仍不授权发布。

只准备物料时到本地结束。真实平台裁切、话题绑定、上传、草稿和发布另交 [Agent-Publish](/Users/xpw/.agents/skills/Agent-Publish/SKILL.md)，遵守当次明确授权；不能为了做视觉检查自行上传或保存平台草稿。
