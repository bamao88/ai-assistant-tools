# 平台标题、正文、关键词与来源

本页是猫猫电视机账号当前文案规则真源；通用写作／平台模板通过 [content-package-create](/Users/xpw/.agents/skills/content-package-create/SKILL.md) 复用，字段转换读 [execution.md](execution.md)。默认处理外部被动节目视频。独立知识／进展笔记使用本篇真实主张，不套节目固定前缀、观看说明或视频来源字段；封面读 [note-cover.md](note-cover.md)。

## 先取事实，再写

读取当前 item、真实连续画面／动作、原平台／作者／原题／链接／时间码、本次使用依据、权利状态和近期已认可笔记。账号当前非官方；默认海外YouTube连续片段，其它来源／完整原片按逐条例外记录，产品素材按项目授权边界处理。不得虚构官方、原创、已授权、亲历猫咪反应、真实互动、数量、时长或健康／治疗效果。

每条材料分别维护：平台标题、正式分段正文、关键词数组、视频来源署名／链接、知识核对资料、内部备注。`copy.body` 不混入来源、原链接、原题／@作者、片段剪辑／完整转发说明、话题串、权利状态或审核笔记；来源不全时如实记录限制，不自动补回正文或执行平台关联原笔记。

## 平台标题

外部被动节目使用 **`给猫看的动画片| `＋本期主题**，竖线后一个半角空格。主题准确、自然，面向本期真实内容，不另设候选数量、策略频次或命名词表；兼顾目标平台实际标题限制。封面 `cover_title` 与平台 `post_title` 分别维护，互相呼应但不要求同字，平台前缀不加在封面名上。

可从对象、实际动作悬念、主人的观看场景或真实数量／时长选择表达角度。旧对标整句示例不覆盖固定前缀，也不能照抄“没有一只猫会拒绝”“我家猫每天都看”等无依据承诺。记录内部 `title_strategy_id` 和1–3个实际相关 `benchmark_refs`，不为凑数跨策略引用；参考代码与原样本见 [对标证据](benchmark-evidence.md)，它不是第二份生成规则。

## 按已确认笔记选择正文类型

`cat-fact`：近期 item-009—013 的「节目标题＋一条猫咪冷知识」是可追溯结构；用户要求参考这批笔记时沿用。一条正文讲清一个实际问题／事实及必要的判断边界，保留独立 `fact_sources`（资料标题、原链接、核对范围／日期）。优先读取能直接支持内容的资料，按事实转述，不擅自把已有指定来源换成另一篇，也不将文章转述当作转载授权。不要向知识正文硬塞全屏／设备提示。

`viewing-guide`：用户要求观看指引或当前认可结构如此时，先用一句描述本片真实对象／动作，再自然接全屏与手机／平板／电视的观看提示，简短提醒设备放稳、低音量、陪同及猫咪个体差异。无真实猫咪观看证据时不假装亲历，不编不存在的主页导航；公共使用说明可复用，画面描述须随真实片段改变。

两类均自然分段，通常保持短正文；现有账号检查器使用约40–180个非空白字符，观看说明常为70–130字。这是当前本地写作约定，不是平台通用字数下限。正文类型、事实、用户已确认表述优先，不能为迁就其它账号模板凑200字。需要例外时记录适用原因，不能把通用检查失败说成通过。

两类正文**均继续生成关键词**。选择知识正文不是跳过账号包装的理由。未知类型先厘清本篇结构，不擅自套成观看说明。

## 关键词／话题

`copy.keywords` 为7–9个真实相关的纯词字符串数组，不带 `#`、`[话题]`，不与正文拼接；不得搬入别的账号关键词池或照抄某旧item整组。

- 观看指引的稳定品类词：猫、猫咪电视、猫咪动画片、猫咪日常；再结合具体对象、上位类别和真实观看场景。
- 知识正文保留猫咪电视、猫咪动画片，其余围绕本片真实对象与本条知识主题选择，例如对象／类别、行为问题、相关场景，不强制塞观看说明词。
- 使用实际对象词；不凑无关热门标签。被动视频不用猫咪游戏／猫游戏／互动标签，不用猫猫最爱等绝对反应承诺，也不加与本条无关的好物分享、解压等标签。

关键词按选定顺序独立展示。小红书按 `keywords` 导出，抖音取前5个，B站按既有字段合同转换；本地导出不等于平台真实话题已选择或绑定，发布阶段另按实际限制处理。

## 互动钩子：结尾段、叠字、置顶评论与策略标签（2026-10-20 起）

当前目标是放大流量并带出游戏制作活动。被动节目每条准备三处钩子，各有作用；正文与评论围绕同一对象、同一主要问题，表达互补，不另开一轮征集：

| 位置 | 字段／产物 | 作用 |
| --- | --- | --- |
| 正文最后两段 | `copy.body_cta`（及 `platform_overrides`） | 告知已有的游戏版，请读者留言是否想让本期对象也变成游戏 |
| 视频画面顶部 | `video.overlay` | 提醒主人叫猫过来看（「快叫猫猫过来看！」），不引导游戏或评论；见 [overlay.md](overlay.md) |
| 发布后账号自己发的置顶评论 | `copy.pinned_comment` | 用例子或表情降低回答本期问题的门槛 |

**结尾段 `copy.body_cta`**：小红书默认版，单独成段（可两小段），必须是 `copy.body` 的最后部分，非空白字符不超过60，只给一个动作、最多一个问题。负责人确认的格式：

```text
小老鼠节目已经有游戏版了，点击链接就能给猫猫玩啦

想让{对象}也变成游戏吗？告诉我
```

它是正文里**唯一**允许出现「游戏」「互动」的位置；其余正文、标题、关键词仍禁用。只写真实已有的游戏版，不写效果承诺，不写「够多少人／赞才做」之类的门槛，不在文字里贴外链，不放来源或授权说明。检查正文字数时不计入结尾段。

「点击链接」只在小红书成立：发布时必须在笔记上挂对应游戏小工具链接并读回确认，挂不上就改正文，不发带「点击链接」的文案（导出包会写明）。

**平台改写 `copy.platform_overrides.{douyin,bilibili}.body_cta`**：抖音、B站不能照搬「点击链接」时单独写，导出时替换最后部分，小红书不受影响。当前已确认版本为「小老鼠节目已经有游戏版了」接本期对象的问题，不附「网页版也快上线」等未经确认且易随排期失效的预告。今后入口实际可用并获确认时，再按对应平台真实入口调整；已提交稿件不随本地规则自动改动。改写版适用同样的文字规则。

**置顶评论 `copy.pinned_comment`**：准备供发布后账号使用的评论，一条只给一个动作，不超过120个字符，与结尾段对象一致，用简短例子或表情降低回答门槛，不另问其它动物或问题。动物、物品均以实际对象自然命名，例如彩带、羽毛小球不硬称动物。生成文字不等于已发出／已置顶，实际操作仍按当次对外动作授权执行。

**策略标签 `copy.strategy_tags`**：本条参与的运营试验，取下表编号，用于后续按标签汇总数据；同一批次只让一层变化，其它层保持一致。

| 编号 | 含义 |
| --- | --- |
| E0 | 基线：无互动钩子 |
| E1 | 提问／投票：评论区说下一个想玩的动物 |
| E2 | 制作过程公开 |
| E3 | 共创：起名、选音效、选玩法 |
| E4 | 试玩日／上线 |
| E5 | 收藏提示 |
| H1 | 对象型标题 |
| H2 | 搜索词标题 |
| H3 | 合集型 |
| H4 | 可玩预告 |
| P1 | 发布时间试验 |
| P2 | 跨平台差异 |
| P3 | 达人试点 |

发评论本身是对外动作，导出包只记录文字；发布时按当次授权执行，不绕过发布 Skill。游戏上线笔记、制作过程笔记属于独立内容型笔记，不套被动节目正文规则，封面读 [note-cover.md](note-cover.md)。

## 来源与署名

`source` 保存平台、频道／作者、原题、原URL、素材ID、原片哈希、使用依据与真实权利状态。当前条目只有本次明确单项例外才可写 `exception_approval`；本地目录存在不是使用许可。

`copy.source_credit` 按真实平台、作者、原题及处理方式填写。连续截取写“本条为片段剪辑”；获批准的完整原片写“按原片完整转发”。它用于独立来源资料和平台必填转载字段，不自动授权 @作者、引用笔记或其它关联。知识来源另放 `copy.fact_sources`，不与原视频来源混淆。

## 写回、示例与检查
