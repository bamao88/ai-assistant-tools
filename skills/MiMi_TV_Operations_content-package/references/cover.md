# 节目封面规则

适用直接供猫观看／游玩的节目封面。内容型知识、变化或进展笔记读 [note-cover.md](note-cover.md)。本页维护本账号现行画风、封面名及验收；不再回旧 profile/planning 或旧社交封面 Skill 找现行规则。

## 信息与画布

- 正式主封面精确 3:4、1080×1440。按目标平台实际需要制作独立比例，写入 `cover.platform_variants`；不能把一张竖版存在视为其它裁切已验收。
- 上方紧凑彩色 `MMTV` 与品类栏目；被动视频标 `猫咪动画片`。只有真实互动且素材获单项使用批准时才标 `猫咪游戏`，不能由原片名称猜出互动能力。
- 主节目名为 `cover.cover_title`；左下小型 `猫猫电视机` 品牌贴纸；右下 `频道 NN`，数值来自 `channel_number`，两位显示。
- 不显示时长、计时器、播放按钮、平台UI、虚构指标、官方／原创身份或功效承诺。品牌与栏目保持小型，节目名与对象主导画面。

## 封面名

名称贴合本期内容，并与画面共同形成辨识与吸引力。可以是名字、短语、问句或有作用的标点；不强制对象名、固定前缀、叠词、角色昵称、儿童故事式、固定字数或分行数。不规定候选数量或策略配额，不为了统一系列只换动物名。

对象信息可由画面补足；轻巧拟人或比喻可以使用，但不能使人误以为视频包含实际没有的情节、交互、效果或真猫反应。涉及动作时核对连续片段，单帧不能证明整段行为。选定名称作为本轮输入，负责人要求调整、事实／错字或缩略图问题时可重新命名并同步图像和字段。

平台 `copy.post_title` 是另一个字段，规则见 [copy.md](copy.md)；改平台标题不自动重画封面，也不把平台固定前缀套在封面名上。

## 制作与追溯

1. 从 item 取得实际对象／动作、来源、品类、封面名、频道及本次适用的已认可视觉，不从旧文件名猜新事实。
2. `real_frame`：从真实源视频按时间点选帧，只裁切／缩放并保存视频路径、帧时码、输入哈希。
3. `ai_processed`：把真实节目对象／动作作为参考，用 [imagegen](/Users/xpw/.codex/skills/.system/imagegen/SKILL.md) 简化、统一并突出对象；不擅加额外动物、无关道具、复杂叙事、密集纹样或固定爪印。AI包装不能冒充真实节目截图。
4. 当前确定性中文／品牌覆盖层**尚未复建到认可画法**。可制作携带旧图的整图AI合成稿，如实记录 `prototype / ai-composited text`；背景单独生成时不含文字／logo，后续覆盖层只有在与旧图匹配后才可用于生产。不能把“将来用脚本合成”的方案写成当前已具备能力，也不能用普通字体代替。
5. 保存提示词、参考图、生成工具、构图模式、模板版本、最终文件与哈希。正式图固定为 item 内 `cover.png`；其制作证据按需放 item 的 `work/`，通过 `cover.background` 引用。item 是唯一长期清单，不再另建一份可独立改写的封面 JSON。

## 质量与批量适用条件

新对象／背景压力类型或模板迁移先做代表稿；旧迁移计划的三类 canary 为深色大对象、小型或成组对象、真实互动节目。跨类型模板迁移在三个代表类型实际通过前不能声称整体迁移完成或批量能力已验收；C1 A16曾获视觉确认，C2/C3历史探索不自动升级为本次通过。互动素材仍受项目单项使用批准约束，canary 不扩大素材权限。已被当前模板覆盖的常规新节目默认一张，不重新开放多版抽卡；用户要求探索时按需要比较。

- 单图：准确对象／动作，背景简单、对比明确，文字无错字、主体无遮挡，栏目和品牌不抢画面，画布和实际需要的比例正确。
- 系列：与最近至少5张可用旧封面作 contact sheet，同时看大图与约120px宽缩略图。先读节目名，再识别对象，最后看栏目和频道；固定模块过大、画法明显突兀或机械重复均需修正。没有足够历史图时如实写样本不足，不虚构已覆盖5张。
- 运行本目录 [封面检查器](../scripts/check_cover_package.py)，再实际目视；通过字段／尺寸检查不代表画风匹配或负责人接受。
- 错字、频道或局部遮挡只修相应部分；背景有问题修背景。连续两轮未收敛或多个节目同类失败时重新检查模板判断，不继续逐张堆提示词补丁。
- 首批／模板变更需要的真实平台裁切、清晰度和安全区验证，留到另获平台操作授权后执行。本次仅本地包时标 `platform preview: not-performed`，不得自行上传草稿。公开证据与负责人接受分别记录。
