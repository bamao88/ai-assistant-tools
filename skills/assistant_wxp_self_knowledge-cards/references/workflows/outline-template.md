# 分页大纲模板

沿用原方法的 Position、Core Message、Text Content、Visual Concept、Layout；在逐页填写前，先列材料如何分组。没有额外的分析流程，也不要求重做已确认内容。

## 文件命名

通常只写 `outline.md`。需要比较不同方向时，才写 `outline-strategy-a.md`（故事驱动）、`outline-strategy-b.md`（信息密集）或 `outline-strategy-c.md`（视觉优先），可组合使用。

图片：`NN-{type}-{slug}.png`；提示词：`prompts/NN-{type}-{slug}.md`。
`type` 使用 cover/content/ending，slug 用简短且不重复的内容英文短名。文件命名不强制增加一张独立封面或结尾。

## 布局选择

| Layout | 适合承担的任务 |
|---|---|
| sparse | 标题、态度、停顿或单一主视觉 |
| balanced | 文字与情境、图示共同解释 |
| dense | 需要同屏查看的清单、关系或多项事实 |
| list | 并列项；只有实际有先后时才标步骤 |
| comparison | 同维度对照；保持对象、尺度和标签可比 |
| flow | 真实有依据的过程、流转或时间关系 |

布局可逐页变化。元素资料中的要点数量与留白比例仅供试排，不是配额；封面不一定最稀疏，尾页也不一定是CTA。信息密集和漫画趣味可以共存，靠层次与图文分工解决，不能统一改成几行文字加小图标。

## 大纲格式

下面是编辑字段，不是上图文字。没有来源支撑的内容保留待核，不据模板编造。

```markdown
# 图卡大纲

---
strategy: a  # a/b/c或组合，仅作组织视角
style: custom  # 已选本包预设，或在下方写清自定义风格
image_count: 待试排后填写
---

## 整组
- 阅读目的与封面承诺：
- 文稿依据：新写或复用的连续稿；已修正的概念、主体与逻辑缺口（适用时填写）
- 深度边界：哪些细节必要，哪些旁支退出本篇：
- 材料分组与关系：各组已有理解、推进依据与预期新理解；并列/前提/对照/证据等
- 页数与分配理由：哪些同屏、哪些跨页；有指定数量时如何取舍
- 视觉约定：画幅、笔触、配色、角色；沿用的对象、标签和颜色
- 本轮参考：分别说明角色、画风、正文密度或构图用途

## Image NN of N

**Position**: Cover / Content / Ending
**Core Message**: 这一页要完成的理解、判断或感受
**Layout**: 按本页任务选择
**Slug**: 页面内容短名
**Filename**: NN-content-slug.png

**Text Content**:
- Title: 「逐字标题；无需标题时省略」
- Body/Points: 「逐字正文；不限制为一两个知识点」
- Speech: 「逐字气泡对白；不加“人：”“AI：”前缀」
- Labels: 「确需上图的逐字标签」
- Footer/Page: 「需要时填写」

**Visual Concept**:
先写本页要解释的关系或表达的感受，再选合适的图示、场景或动作；读者先看哪里，再看哪里。无需为避免雷同强制换版式。
图承担的理解、证据、趣味或情绪；跨页不变与变化的参照。
解释性图示（可无）：先写它使什么抽象概念或关系更直观，不能仅因文字已说明就删图；确有必要时才列节点/标签/方向/条件，以及与正文句子的对应。
情境小插图：如有，说明占用空间的理由；不能顶替必要解释。

**Context**（不上图）:
属于哪组材料，与前后页怎样相接；为什么同屏或拆页。
理解推进：读者到这里已知道什么，本页借哪个例子/依据使他多理解什么；跨页单元写本页承担的部分，不重开整套背景。
图文配合：按需要说明对白、正文、例子、图示怎样共同推进；不要求每种形式齐备，避免轮流复述同一结论。
主次关系（机制解释适用）：标题与主图解释哪条一般关系，例子附在哪个节点/短段，哪些做法仅限本例；不固定成上下两个区。
来源与未知边界；需要保留的原话或参考图。
演示产物如文档/界面是否是假设示意；需要标明“示意”时，将标识另列入上图Labels。
对白归属：按对白出现顺序逐条注明说话角色与气泡尾巴指向；角色名称是编辑说明，不并入逐字对白。

---
```

按实际需要省略空字段。气泡或旁白使用大纲中逐字列明的文案。通过角色和气泡尾巴区分说话人，成图不重复“人：”“AI：”标签；说话归属单列于不上图的 Context，与逐字对白分开。允许为解释知识创作示意对话，需写明用途和说话人，不冒充真实对白；以完整回答解释问题，不用空泛附和充当趣味。自然承接即可，不添加固定 Swipe Hook、收藏号召或评论问题。

理解推进是编辑判断，不是每页统一的“误区→反转→答案”版式。具体例子可同时带来趣味和知识，对白也可承担理由，图示也可产生发现；按内容组合。文字充分以理由、关系和条件讲清为准，不追求字数或术语配额。

## 分页示例：同一问题可以有不同安排

以下是结构示意，不是新的事实或已选大纲：

- **两种“通过”的理解**：若各自含义很短，同屏比较检查范围；若读者缺少前提，先解释对象再合看。
- **同一次排查经历**：可以跨页呈现困惑、尝试、后来发现，沿用同一个问题与对象。每页增加理解，不需要每页重新总结。
- **几个排查方向**：适合并列呈现时可以同页列出，不画成必须依次完成的流程；太密时按含义分组。
- **真实的未解问题**：可以独立收尾，也可以融入最后一个场景，不强行补答案或学习路线。

## 大纲检查

- 先有材料关系，再有页号；无需固定“痛点→干货→行动”顺序。
- 每页文字与画面共同服务本页任务；同一问题可多页，一页可多项。
- 读者从已有理解走到什么新理解，是否有具体依据；标题、对白、正文、图示、结尾是否连续同义重复。
- 对照维度一致，箭头有依据，来源与不确定性没有被压缩掉。
- 机制篇只读标题仍能跟上主线，暂去例子仍能复述关系；前提先于依赖它的解释，具体案例没有夺走本页学习目标。
- 图示选择来自关系而非版式多样性；交互图标清主体与返回方向，反馈图容纳正常继续和因问题调整。
- 重复参照、回看总览、人物反应和情绪停顿按作用保留。
- 页数、深度、信息量、趣味与手机可读性一起检查；页数过多先优化范围，不无限拆页；保留主线解释，不用压缩为标签替代内容取舍。
