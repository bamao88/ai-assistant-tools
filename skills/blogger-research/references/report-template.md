# 博主调研报告模板

成稿结构。每个维度给**结论 + 数据支撑**，不要只堆数据，也不要暴露抓取过程。

---

## 1. 博主画像
- 一句话定位：这个号是谁、给谁看、解决什么。
- 量级：粉丝 / 累计获赞收藏（小红书）或 平均阅读·在看（公众号）。
- 内容赛道与人设（专业型 / 人格型 / 资讯型 / 带货型…）。

## 2. 选题分布
- 高频主题聚类（占比），用表格列 主题 → 篇数/占比 → 代表作。
- 内容形式占比：图文 / 视频 / 长文（小红书）；头条 vs 次条、原创 vs 转载（公众号）。
- 选题策略判断：垂直深耕还是泛领域？追热点还是做常青？

## 3. 爆款规律
- 列 Top 互动内容（标题 + 关键互动数），找共性：
  - 标题套路（提问 / 数字 / 痛点 / 反差 / 身份标签…）
  - 封面 / 首图风格
  - 内容结构（开头钩子、节奏、结尾 CTA）
  - 话题标签 / 关键词
- 一句话总结"什么样的内容在这个号上会爆"。

## 4. 发布节奏
- 频率（周更几篇）、活跃时段、是否有系列/栏目化更新。

## 5. 互动数据
- 平均 / 中位 赞藏评（小红书）或 阅读·在看·点赞（公众号）。
- 爆款 vs 长尾的差距，互动结构（评论区共鸣点，如有抓评论）。

## 6. 可复用结论（给对标用户）
- 如果要对标这个号做内容：**能抄什么**（具体到选题角度、标题结构、发布节奏）。
- **要避什么**（它踩过的坑 / 不适合迁移的部分）。
- 3 条以内可立刻执行的建议。
