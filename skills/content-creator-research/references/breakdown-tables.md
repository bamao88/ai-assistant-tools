# 账号研究分析字段

按需取用以下十个分析维度；不要求每次填满十表。旧来源为本地 `个人整理-短视频拆解excle模版.md`，仅作分析启发，不是平台算法、健康阈值或官方数据定义。

有证据才填；未取得、无法判断、不适用要区分。人口画像、收入、起号时间等不得由零散评论或最早可见日期补猜。

| 维度 | 可选字段 | 说明 |
|---|---|---|
| 1. 基础信息 | 昵称、账号链接、简介、平台公开粉丝/作品/互动、最早可见作品、读取日期 | 列表枚举量与总作品量分开；量级只作背景 |
| 2. 定位与人设 | 自述身份、内容承诺、目标人群、主题边界、主页风格、差异 | 区分自述与研究解释 |
| 3. 受众与需求 | 明确针对的人群、评论问题、使用场景、未回答的需求 | 公开评论是局部反馈，不是整体粉丝画像 |
| 4. 选题系统 | 主题聚类、系列、常青/热点/季节、人群×场景×问题、关键词 | 数量和占比只对明确样本成立 |
| 5. 内容形式 | 图文/长文/视频、口播/实拍/录屏、画面、节奏、字幕、音乐、封面 | 没读的媒体不能分析其内容或效果 |
| 6. 表达结构 | 标题、开头、主体展开、论据、结尾、互动引导、代表句 | 分类见 hook-formulas.md；分类不是成效原因 |
| 7. 运营节奏 | 发布时间、频率、栏目、公开回复、置顶、跨平台关联 | 描述观察，不默认最佳时段或更新频率 |
| 8. 商业化 | 公开广告标识、产品、收费入口、转化说明 | 仅任务需要时展开；不猜收入、转化或私下报价 |
| 9. 代表作品 | 链接、日期、主题、形式、可得指标、实际内容、可借鉴点 | 同时考虑普通作品及例外；不固定 Top N 或时间窗 |
| 10. 迁移判断 | 适用目标、条件、制作成本、需改动处、待验证问题 | 由当前项目决定，不给通用复制公式 |

可复算指标如赞藏评中位数、频率或比值，要说明时间窗、分母、单位与缺失。只选高互动样本时不能写成账号总体指标。指标值不能直接推出内容质量、造假或账号健康。
