# 采集与证据规则

轻量、单号深拆、多号比较、专项表达分析和赛道研究共用。平台说明见 [小红书](xiaohongshu.md)、[公众号](gongzhonghao.md)、[视频号](shipinhao.md)；平台参数的真源是对应 `platform-fetch/references/`。

## 先用已有材料

用户提供的导出、原文、截图、字幕和项目既有研究可以作为输入。先核对来源、时间和覆盖范围；只对影响本次结论的缺口补采。历史报告是二手结论，不能当作本次独立读过原作的证据。

公开采集使用已授权的只读会话。小红书使用测试会话，本地 CLI 显式传 `--account 测试号`；视频号按当前平台 reference 解析测试环境。不要因限流、登录或 token 失败改用正式账号、无登录 Cookie 或绕过验证。

## 按问题采样

- 轻量了解：账号自述和能回答核心问题的代表作品即可；说明只是初步认识。
- 单号深拆：考虑近期与历史、不同主题/形式、高互动与普通作品。不是每次都要覆盖所有维度。
- 多号比较：尽量统一时间窗、作品形式和指标定义；无法统一则分列差异，避免硬排名。
- 标题/封面/评论专项：采集相应内容本身。标题不能证明正文结构，评论样本不能证明全部粉丝画像。
- 赛道研究：记录搜索词、时间与采样来源。推荐流、搜索排名和已知账号都存在选择偏差。

采集数量随证据缺口调整。不存在最低作品数、固定 Top N、详情成功率或截图数量的通用完成门槛；也没有默认最高篇数。用户要求全量时应尝试当前工具支持的公开分页并保存覆盖证据，受外部限制时明确尚未取得的部分。

## 留下可复算的记录

将中间资料放当前项目约定的研究目录；临时任务可用工作目录。建议保留：

- 原始列表/详情或用户材料的位置，以及实际读取时间。
- 账号标识、作品链接/ID、发布时间、类型、实读范围。
- 列表覆盖、详情成功项和失败项、选择样本的理由。
- 统计表所用字段、计数单位、缺失值和分母。

只在执行需要时处理 token，不把登录凭据或历史 token 写入报告、测试样例或共享文档。报告引用可访问链接、稳定 ID 或本地证据位置；原始响应中的认证资料留在受控环境。

## 字段与指标

按实际响应核对 schema。不要假定不同平台、不同命令都返回同一层字段。

| 研究信息 | 使用原则 |
|---|---|
| 账号基础信息 | 使用平台实际公开字段；粉丝数未知就标未取得 |
| 作品总量 | 列表长度是本次已枚举量；只有平台明确给总量时才称账号总作品数 |
| 起号时间 | 需要账号自述或其他直接依据；最早可见作品仅是最早可见日期 |
| 发布时间/频率 | 列表缺日期时按需补详情；时间窗不完整时不计算整月频率 |
| 作品表现 | 保留平台实际指标名和读取时间；缺失不记为 0 |
| 互动分布 | 说明是全部可见、近期还是高互动样本；必要时比较中位数、范围与例外 |
| 商业化 | 可分析公开广告标识或产品路径；不能推断未公开收入、报价或转化率 |
| 受众 | 区分账号希望服务的人群、内容中的需求和有依据的实际受众；不能从头像/昵称猜年龄、性别、职业或收入 |

跨平台的点赞、阅读、转发、在看和播放等不能合成同一种效果。对公开互动较高的作品，可提出标题/封面/选题作用的假设；缺少曝光、点击或留存数据时，不写因果证明。

## 异常与覆盖

按工具的具体错误分类处理；空结果可能来自会话、token、加载、字段或权限，不直接诊断“博主私密”“风控”或“已删除”。可用有依据的恢复动作；遇到验证页、明确限流或权限限制时保留现场并停止当前采集路径，不空转重试。

详情缺失不意味着整轮研究必须废弃：继续可回答的部分，明确缺失对判断的影响。原任务需要的关键材料仍不可得时，报告部分完成或外部阻塞及恢复条件。

`no_growth`、滚动次数上限或列表没有新增都不单独证明全量。检查目标账号、分页返回、明确结束标记和错误状态，再描述“本次可见公开列表已到末尾”。私密、已删除或未展示内容不在覆盖声明中。

## 交付核对

账号与作品是否对应；关键结论是否来自实读材料；分母、时间、采样偏差与缺失是否清楚；输出是否区分事实、解释、假设；是否保留可追溯证据且没有执行写操作。补证只围绕会改变本次结论的缺口展开。
