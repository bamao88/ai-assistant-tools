# 钩子公式参考

原分类来源：本地麦田《博主入门指南——小红书运营十一讲》。以下分类用于描述样本，不是平台官方机制、通用创作公式或成效保证。按实际内容增加或调整分类；某类做法是否有效需要对应指标和证据。

---

## 封面视觉锤：五大模板

观察主体、文案、信息结构与内容承诺。公开互动不能证明点击率；分析时标出实际可见内容和未取得的效果指标。

| 模板类型 | 设计要点 | 适用场景 |
|---------|---------|---------|
| 人物主体 + 精炼标题关键词 | 用人物作视觉焦点，文案撩拨好奇心 | 人设型账号、生活类博主 |
| 连环画（四分构图）+ 关键文案 | 通过 4 格图构建故事性，一眼洞悉内容 | 步骤教程、改造前后 |
| 反差（二分构图） | 选两张强烈反差图片，展示前后变化 | 改造类、减肥类、逆袭类 |
| 备忘录/笔记式 | 手写笔记或清单形式，增加真实感实用性 | 干货教程、经验分享 |
| 窥私欲（评论/聊天截图）| 展示真实对话或评论，激发好奇心和参与感 | 情感类、职场类、社交技巧 |

## 标题公式：六大类型

记录标题表达方式与内容兑现关系；数据可比时再比较公开互动。标题类型和互动的关联不能单独证明标题带来成效。

| 公式类型 | 结构特征 | 例子 |
|---------|---------|------|
| **数字式** | 量化效果，直击要害 | "1个月成功减掉20斤" / "装修避坑的7个细节" |
| **悬念式** | 强烈警示或疑问，促使解开真相 | "同事突然变得热情，千万要注意！" |
| **利益诱惑式** | 直接展示成效或改变的价值 | "学会沟通让我半年连升两级" |
| **设问式** | 一对一交流感，激发探索欲 | "如何在一个月内搞定雅思？" |
| **对比式** | 悬殊对比展现直观画面 | "从180到110斤，周围人态度的变化" |
| **恐惧式** | 引起忧虑，促进反思 | "警惕！'让孩子成为学霸'的陷阱" |

拆解时重点关注：
- 博主最常用哪 2-3 种标题类型？
- 不同类型在本轮样本中的公开反馈有什么差异？（注明时间、分母、选择方式和反例）
- 标题关键词有哪些高频词？

## 文案结构：一种常见分类

**可观察结构示例**：开头 → 主体展开 → 结尾。不要为了套三段式而忽略作品实际结构，也不要求所有作品都有 CTA。

### 开头表达（按作品实际长度与形式观察）

| 钩子类型 | 例子 |
|---------|------|
| 问题提出 | "你有没有发现，同样是装修，为什么别人的家这么好住？" |
| 数字冲击 | "我花了 3 年踩了 20 个装修坑，终于总结出这份清单" |
| 反常识结论 | "收纳越多，家越乱——这是很多人搞反了的事" |
| 身份共鸣 | "作为一个独居 5 年的北京女生，我想说…" |
| 场景代入 | "每次下班回家看到这个角落，我就想搬家" |

### 内容主体结构

| 内容类型 | 结构 |
|---------|------|
| 避雷/干货型 | 踩坑案例/数字冲击 → 原因拆解 → 避坑清单 |
| 改造型 | 现状（凌乱/问题）→ 改造过程 → 成品展示（前后对比） |
| 教学型 | 概念 → 原则 → 案例 → 可复制步骤 |
| 种草型 | 场景感官 → 痛点共鸣 → 产品解决方案 → 使用效果 |

### 结尾 CTA 设计

| 方式 | 例子 |
|------|------|
| 互动引导 | "你们家是怎么解决这个问题的？评论区聊聊" |
| 资料诱饵 | "评论'清单'，发你完整版装修避坑清单" |
| 系列引导 | "下一期出XXX，先关注不迷路" |
| 主页引导 | "主页置顶有完整的改造全流程" |

## 种草文句式分类

| 关系 | 句式模板 |
|------|---------|
| 并列 | "一种是…一种是…" / "要么…要么…" / "今天…明天…" |
| 转折 | "与其…不如…" / "没有…只有…" / "幸好…" / "三分…七分…" |
| 递进 | "有多…就有多…" / "没有…就没有…" / "不是…而是…" |
| 假设 | "只要…哪里的…" / "只要…全世界…" / "如果没有…" |

## 评论区观察

研究公开评论时，可描述以下做法及真实反馈，而非自动建议用户照搬或代为执行：

- 作者是否提出问题、邀请分享经历，评论是否回应内容主题。
- 是否提供资料或引导进一步阅读；交付条件和作品承诺是否清楚。
- 作者回复是否补充信息、澄清问题，以及留言中的持续需求。
- 置顶评论、系列入口或主页内容与作品的关系。

争议、资料引导或回复数量本身不能证明权重提高、转化或粘性增长。评论只是可见样本，不代表全部受众；不用头像和昵称推断人口画像。这里只观察，不发送评论、点赞、收藏或私信。
