# 内容运营总账维护

通用能力：账号定位、事实、素材与输出位置遵循当前项目；项目已有专属入口时优先沿其规则衔接。

让一个日常入口持续反映“原稿在哪里、什么时间发、目前可见状态、哪次采集的数据、下一步做什么”。模板和引擎不含项目账号、选材限制或特定项目路径；这些由调用项目的配置和专用Skill提供。

## 使用入口

- 已有项目：先读取项目维护Skill、配置、总表和待办。复用已有稳定ID、真实原稿和历史快照，不能新建第二套账。
- 新项目：从 [通用总表模板](assets/CONTENT_MANAGEMENT.md) 与 [配置模板](assets/ledger.config.json) 初始化；映射现有作品／发布／指标路径。路径以 `--root` 为基准，平台账号以配置为准。
- 本地命令、输入格式与指标含义见 [数据合同](references/data-contract.md)。进入平台采集时再读 [后台核对](references/platform-reconciliation.md)。
- 项目复盘与后续优化由项目专属Skill组织，按需读取 [复盘执行方法](references/content-review.md) 与 [分析参考](references/retrospective.md)。通用 [报告模板](assets/CONTENT_REVIEW.md) 和 [迭代简报模板](assets/CONTENT_ITERATION_BRIEF.md) 独立复用，不需要再拆一个可调用的通用复盘Skill。

```bash
python3 <本Skill>/scripts/ledger.py --root <项目目录> --config <配置.json> --queue
python3 <本Skill>/scripts/normalize_exports.py --root <项目目录> --config <配置.json> --manifest <本轮清单.json> --out <新快照.json>
python3 <本Skill>/scripts/ledger.py --root <项目目录> --config <配置.json> --import-snapshot <新快照.json>
python3 <本Skill>/scripts/ledger.py --root <项目目录> --config <配置.json> --check
```

## 每次维护的完成条件

1. **先定本轮范围。** 区分状态核对、指标采集、计划调整和复盘；维护台账不授权改平台原稿。沿用本次授权的正式环境，实际核验目标账号；浏览器可用性和登录状态分别判断。
2. **按待办采真实数据，以官方导出原表为主。** 各平台有原生导出时先下载表格、保留原表后处理；后台卡片只核身份、状态、排期及总量，不把卡片数字当作新官方导出。 优先处理已过定时但未核实、提交结果不明、到观察窗口、后台总量差异、上次采集失败的账号。读取所有相关分页／懒加载，记录筛选条件、总数和实际采集时间；留存日期化证据，缺什么写什么。
3. **先匹配原稿再补字段。** 原生ID优先，其次平台链接；没有ID时结合标题、首次时间、时长与内容核对，并保留匹配依据。标题相同不自动合并，当前制作包不冒充已发版本。账号历史、私密旧帖也可入账，但与本轮项目内容分开统计。
4. **把事实写回原账。** 计划、提交、定时、首次发布是不同时间；公开可见范围独立记录。指标按发布ID、口径、时点追加；缺失不能补零，平台原生比例不能换分母反算。新导出只有部分指标时不删除旧指标，展示旧值必须带原采集时间。原表给0但官方页面明确未就绪／缺失时，保留原值并附有证据的quality标记，不把待更新占位当真零。
5. **形成下一次动作。** 更新后台总量核对、缺口原因、下次检查时间和采集窗口。错过窗口保留真实稿龄，不能补造D+1；失败留下恢复动作，不拿“已检查”冒充已补齐。没有数据支撑时保留假设，不强行给内容结论。
6. **刷新并验证总表及受影响的判断。** 检查状态、关联、来源、重复快照、后台总量差异及生成同步；保留手写决定。新数据会改变取舍时同步当前复盘报告，周复盘不能只更新数值。报告实际采集范围、剩余缺口和下次维护条件。离线校验、真实后台采集、本地导入与用户验收分别报告。

## 持续执行

维护触发点是：平台提交后、计划公开到点后、实际公开后的配置观察窗口、每周下轮选题前，以及人类要求更新时。发布／采数／复盘任务都必须写回同一入口，不能只更新聊天。

常规维护不需要每次重问已授权的账号与只读范围。遇登录认证保留原页，只有需要人类认证时请求补位；不得以采集失败为由换账号、重传、取消定时或改权限。

Skill规定做法，调度器负责何时唤醒。用户要求周期执行时使用当前环境支持的自动化工具，优先更新同一项目的既有任务，提示词只引用项目维护Skill与实际目录；只读采集权限不扩展为发布权限。未创建或未验证的调度必须如实说明，不能声称“以后会自动维护”。
