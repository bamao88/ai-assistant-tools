# 长文判断

适用公众号文章、专栏、深度解读、经验复盘与叙事。重点判断是否有值得深入阅读的内容，以及材料能否支撑它；搜索导向文章同时使用 SEO 方法。

## 确定阅读理由

明确读者已有理解，以及文章带来的新理解、判断、经验或感受。选择一种可展开的中心：要解释的问题、要论证的主张、需要呈现的经历或值得重新理解的材料。

宽泛主题先收敛。例如“AI改变工作”尚不足以形成文章；要进一步确定改变了谁的哪项工作、发生了什么、凭什么这样判断。

## 判断材料是否撑得住

| 内容方向 | 需要检查 |
|---|---|
| 来源解读 | 原始来源在说什么，关键依据、分歧和适用范围是否读清 |
| 观点分析 | 主张的理由、反例与条件是什么，是否超出材料所能支持 |
| 经验复盘 | 处境、动作、结果和取舍是否真实，哪些认识可以迁移 |
| 叙事／人物 | 事件与细节如何推进理解或感受，叙述是否有连续性 |

只有一句观点或若干摘录时，决定补材料、缩小范围或改用更短形式。长度由内容需要决定，不能靠扩写填满。

## 用摘要与大纲检验选题

先写接近成文内容的摘要，讲清文章会说什么；再列初步大纲，检查每一部分是否推进中心，而非轮流重复结论。必要概念和背景放在读者需要的位置，次要分支明确不展开。

题目成立的标志是：阅读理由清楚、核心材料充分、内容有增量、结构可以兑现承诺。若缺关键论据，交付选题时同时指出，而不让正式写作阶段自行补造。

交付摘要、大纲、核心来源、独有角度与范围。个人叙事、来源人物的经历和教学示意分别说明，不能相互冒充。
