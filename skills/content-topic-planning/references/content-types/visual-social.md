# 图文／视频判断

适用小红书、抖音、视频号等图文和视频内容。这份方法补充通用流程中的对标研究、观看价值与表达能力判断，具体平台差异依据本次真实样本。

## 如何选参考对象

先明确参考用途：学习题目、呈现方式，还是与目标相关的运营或商业路径。按受众、内容目标、形式及资源条件选择可比较对象。

与自身阶段相近的账号适合观察可行做法；较成熟账号也能提供题目与表达参考，但需识别其品牌、资源和受众积累的影响。粉丝规模、账号年龄和更新频率提供背景，不作为统一排除门槛。

对有价值的方向，比较同账号普通与突出作品，再看其他作者的同题作品。记录实际覆盖范围，避免仅凭单篇成功推导公式。时间窗口按热点、常青内容和本轮目标选择。

## 如何读一篇作品

观察以下关系，而非只抄标题或统计点赞：

| 观察对象 | 提取什么 |
|---|---|
| 题目与受众 | 为谁提供什么实用、情绪、审美或娱乐价值 |
| 标题封面与开头 | 提出了什么观看承诺，靠什么引入 |
| 内容展开 | 用哪些材料、动作、对照或叙事兑现承诺 |
| 评论 | 真实提问、经验补充、认同、质疑与争议，各自指向什么 |
| 表现 | 与可比较样本的差异，指标口径、时间与未知因素 |
| 自身机会 | 哪个问题尚未讲清，我们能提供什么不同材料或体验 |

若只能看到摘要或视频片段，明确观察范围。引用评论保留上下文；热评不是全部受众意见。

## 如何判断观看价值

- **实用／知识**：要解决的问题够具体吗，结论是否有依据，观众能理解或使用吗？
- **情绪／故事**：处境、变化或冲突是否具体，情绪由内容产生还是只有一句口号？
- **审美／娱乐／陪伴**：画面、动作、节奏或新奇体验本身是否成立，是否有可用素材？

收藏、分享、点赞和评论可以辅助解释价值，但不等于价值本身。低粉高互动值得进一步查看，不能据此排除投放、外部传播或偶发因素。累计赞藏、单篇互动与曝光分母不同，不混作一个“互动率”。

## 如何判断形式与自身贡献

图文重点看画面和文字能否互相解释、对比或推进阅读；视频重点看动作、变化、过程或叙事是否值得观看。同一题可以适合多种形式，选择依据是目标、素材与表达能力。

检查自己能讲清或展示到哪一步：已有材料是什么，要补哪段研究、实验或拍摄？暂时做不了的题可保留为学习或研究方向。具体措辞、案例和视觉资产不能只换词冒充自身创作。

同题供给多时，看现有答案是否重复、读者还有什么未满足需求。差异化需要改变内容实质；新身份标签或相似标题不够。开头和内容结构服务题目，不固定秒数、页数或反常识公式。

交付时说明观看理由、图文／视频选择、关键材料与展开路径，足以判断能否做成即可，不提前制作发布包。
