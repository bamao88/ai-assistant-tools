# 研究与判断方法

## 用哪些输入发现机会

选择最能回答本轮问题的来源，不要求每次遍历所有渠道。

| 输入 | 提取什么 | 可形成的机会 |
|---|---|---|
| 受众提问、评论、访谈 | 具体处境、困惑、顾虑和原话 | 未回答的问题、理解误区、决策困难 |
| 完整对标作品 | 为谁解决什么、用什么材料、遗漏什么 | 更合适的对象、新依据、不同判断或呈现 |
| 查询与搜索结果 | 搜索者任务、已有答案与内容类型 | 需要补充的答案、值得更新的页面 |
| 自身经历、数据或素材 | 真实变化、失败、取舍、可展示的内容 | 案例、解释、复盘、故事或观看体验 |
| 新资料与变化 | 哪些旧认识或做法受到影响 | 新解释、更新、核验或比较 |
| 既有作品反馈 | 读者实际在意什么、还问什么 | 延伸、澄清或重新研究的方向 |

账号目标既可以是知识与实用，也可以是审美、娱乐或陪伴。主动创意允许从兴趣与材料出发，尚无受众反馈时如实标为假设。

### 判断证据能支持到哪一步

- 标题与摘要提供线索；判断内容本身需要读取正文、图卡或相应视频。
- 完整作品证明某种内容路径存在；其表现还需对应指标或评论支持。
- 评论与指标支持该样本、该观察窗口的反馈；不能单独证明增长原因或普遍需求规模。
- 自有表现只覆盖已经尝试的内容；缺历史数据不等于新方向无价值。

引用重要发现时保留来源、日期、实际读取范围和局限。区分受众原话、自己的概括与解释假设。来源获取失败时说明影响；不要虚构问题、搜索量、经历或测试结果。

## 如何把材料变成选题

对一个信号依次问：谁在什么场景下关心它？现有内容回答到哪里？我们用什么新增材料或判断把它推进？可以改变的维度包括对象、场景、问题、证据、结论和观看体验。

例如，材料显示“整理收藏后依然找不到资料”：
- **主题**：资料整理。
- **一种角度**：收藏时记录什么，能帮助下次按任务找回资料？
- **另一种角度**：一次找不到资料的真实经历，暴露了分类方式的哪些问题？
- **形式选择**：图文对照、视频演示或长文复盘，取决于材料和目标。

这是方法示例，不是已发生的受众反馈。实际候选要回到自己的来源；新标题或新形式本身不证明存在新选题价值。对标可以帮助发现关系与结构，自身内容仍需独立的材料与表达。

## 如何判断是否值得做

先判断成立条件，再排优先级。

| 成立条件 | 判断问题 | 不足时怎么办 |
|---|---|---|
| 受众价值 | 对谁有什么理解、实用、判断或体验价值？ | 具体化对象与内容承诺 |
| 自身贡献 | 为什么由当前账号或网站做，与参考和旧作相比增加什么？ | 找新材料、角度或更合适的范围 |
| 内容支撑 | 主张、故事或体验是否有对应依据与素材？ | 补证、调整主张，或列为探索 |
| 适配与可行性 | 是否符合已知身份、公开边界与制作能力？ | 更换材料或形式，或暂缓 |

成立不等于现在就做。继续比较目标相关性、需求或兴趣依据、时效、投入、近期内容组合与关键不确定性。既有作品的更新和延伸也可以有价值，说明具体新增部分。

价值、可信度和准备度分开描述。例如“需求有依据、增量明确，但缺演示材料”适合优先补证，不应与“材料齐全但价值不清”的题排在一起仅比制作成本。评分只在有助于比较时使用，注明依据；不同目标不套统一权重。

## 如何补证与解释反馈

找出最可能改变取舍的一项未知，再选最小动作：补读原始资料、检查同题样本、验证关键操作、试写核心解释或做代表性画面。涉及公开测试时另按任务授权执行。

收到反馈后指出它影响的是题目价值、内容范围、证据还是呈现方式。例如“这题太浅”先检查缺少什么解释或判断，不自动扩大到整批重选。实际表现要考虑观察窗口及包装、制作、分发等因素；一次结果不足以确认因果。
