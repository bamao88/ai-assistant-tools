# 输出模板

## 模板 A：单博主深度拆解报告

成稿时：结论 + 数据支撑，不暴露抓取过程，不说教，给洞察而非数据堆砌。

---

### 一、博主画像
- **一句话定位**：这个号是谁、给谁看、解决什么
- **核心数据**：粉丝量 / 赞粉比 / 爆款率 / 平均互动率
- **账号级别**：伙伴（<1万）/ 榜样（1-10万）/ 大佬（>10万）
- **起号时间 + 成长速度**

### 二、账号定位与人设
- 内容定位类型（流量型/转化型/人设型/干货型）及各类型占比
- 人设四层分析：专业背书 / 价值主张 / 情感共鸣 / 行动指引
- 目标用户画像（年龄/性别/核心痛点）
- **差异化优势**：和同赛道其他博主的本质区别

### 三、选题系统解码
- 主要选题方向（Top 3）及占比
- 选题类型分布：常青型 / 热点型 / 季节型
- 高频关键词 + 常用话题标签
- 选题创新点（他做了什么别人没做的）
- **选题规律总结**：什么话题在这个号上容易爆

### 四、钩子与封面
- 常用封面模板类型（五大模板中的哪几种）
- 标题公式分布（六大类型各占比）
- 最高互动的 Top 5 标题（附互动数）
- **标题规律总结**：他最惯用的标题结构是什么

### 五、内容结构拆解
- 呈现形式（图文/视频/口播/实拍…）
- 开头钩子类型 + 例子
- 内容主体结构（避雷/改造/教学/种草）
- 结尾 CTA 设计
- **高频金句** 3-5 条

### 六、数据指标
- 赞粉比：X（评估：高/正常/偏低）
- 平均互动率：X%
- 爆款率（千赞笔记占比）：X%
- 赞藏比 / 赞评比：分析内容属性（收藏多=工具价值强；评论多=情绪共鸣强）

### 七、变现路径
- 主要变现方式
- 商业笔记占比（广告密度）
- 典型转化钩子话术

### 八、可复用结论
**能抄什么**（具体到选题角度、标题结构、发布节奏）：
- 1.
- 2.
- 3.

**要避什么**（不适合迁移的部分 / 他踩过的坑）：
- 1.

**3 条立刻可执行建议**：
- 1.
- 2.
- 3.
