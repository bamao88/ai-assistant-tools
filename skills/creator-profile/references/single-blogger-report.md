# teardown 子能力：单博主深度拆解报告

本文件是 **teardown（博主拆解）** 子能力的**输出契约**。SKILL.md 在完成 10 张表填充后，必须按本文件的"报告骨架"组织成稿，并用文末 checklist 自检。

文件分三部分：
1. **报告骨架** —— 成稿必须有的章节顺序与小标题
2. **完整范例（fixture）** —— 一个真实数据结构的样例，作为质量靶子
3. **验收 checklist** —— 交付前的最后自检

---

写作原则：
- 成稿是**结论 + 数据支撑**，不暴露抓取过程
- 每个章节末尾必有一句"规律总结"，把数据翻译成洞察
- "可复用结论"是全文最重要的部分，必须可执行（"周三晚 8 点发改造类视频"而不是"注意发布时间"）

# 「小南装家」深度拆解报告

> 一句话定位：30㎡ 出租屋改造博主，给一线城市租房独居女性看，解决"不打洞、不动结构、押金不扣"的轻改造问题。
> 调研日期：2026-05-27 ｜ 调研账号：测试号

## 1. 博主画像

| 指标 | 数值 | 解读 |
|------|------|------|
| 粉丝数 | 3.8 万 | 腰部，正处涨粉爬坡期 |
| 作品数 | 87 篇 | 平均 5-6 天 1 篇 |
| 总点赞收藏 | 24.6 万 | |
| **赞粉比** | **6.5** | 落在 3-8 理想区间，内容质量稳 |
| 平均互动率 | 4.2% | 高于赛道均值（2-3%）|
| 爆款率（千赞笔记占比）| 22% | 19/87 篇过千赞，超过 20% 门槛 |
| 账号级别 | 榜样（1-10 万）| |
| 起号时间 | 2023-12 | 17 个月 → 3.8 万粉，节奏稳健 |
| 更新频率 | 周 1-2 篇 | 稳定 |
| **是否可对标** | **是** | 数据健康 + 赛道清晰 + 选题可复制 |

**画像总结**：腰部稳健型博主，不靠爆款赌运气，每篇都在 3%-7% 互动区间，是典型可复制的对标对象。

## 2. 账号定位与人设

**内容矩阵占比**：
- 干货型（避坑/教程）47%
- 流量型（改造前后对比）35%
- 人设型（独居日常碎片）13%
- 转化型（带货推荐）5%

**人设四层分析**：
- 专业背书层："改过 4 套出租屋的租房女孩"
- 价值主张层："不打洞不动结构，押金不扣还能住得好看"
- 情感共鸣层："和你一样租房，但我们值得一个像家的家"
- 行动指引层：每篇结尾给一个"今天就能买/今天就能做"的小动作

**目标用户**：22-30 岁一线城市独居女性，月可支配收入 3000-8000，租房 1-3 年。
**差异化优势**：明确锚定"不打洞 / 押金安全 / 可带走"——租房群体的真痛点，自动过滤了硬装人群。

## 3. 选题系统解码

**Top 3 选题方向**（基于 87 篇笔记标签聚类）：
1. **租房改造前后对比**（占 31%）—— 流量主力
2. **可带走家具/收纳测评**（占 24%）—— 搜索长尾
3. **押金避坑/退租清单**（占 18%）—— 高收藏率

**选题类型分布**：
- 常青型 58%（"出租屋必买"、"小户型收纳"）
- 季节型 22%（春装修季、毕业季搬家）
- 热点型 14%（结合"反向旅行""数字游民"）
- 矩阵型 6%（人群×场景：独居女生 × 退租 × 押金）

**高频关键词** Top 10：押金 / 不打洞 / 出租屋 / 30平 / 拼装 / 退租 / 可带走 / 收纳 / 改造前后 / 北漂

**选题规律**：
- 凡是带"押金 + 数字"的标题，互动率 +50%（如"押金一分没扣"）
- "前后对比"图占封面，点击率显著高
- 转化型笔记每月不超过 2 篇，保持人设纯度

## 4. 钩子与封面模板

**封面模板分布**：
- 反差二分构图（前后对比）56% ⭐ 主力
- 备忘录笔记式 22%
- 人物主体 + 关键词 14%
- 连环画四宫格 8%

**标题公式分布**：
- 数字式 41%（"30㎡"、"省下 3000 押金"、"7 件"）
- 对比式 28%（"从…到…"、"租房 vs 自家"）
- 利益诱惑式 17%（"让房东都夸的改造"）
- 设问式 10%
- 悬念式 4%

**Top 5 互动标题**（截至调研日 180 天内）：
1. "退租那天，房东说押金一分没扣"（2.3 万赞 / 1.1 万藏）
2. "30㎡ 改造前后对比，租房也能住成家"（1.8 万赞 / 9.2 千藏）
3. "出租屋必买的 7 件不打洞神器"（1.5 万赞 / 1.4 万藏）⭐ 收藏 > 点赞，工具属性强
4. "我把出租屋改成 ins 风，花了不到 2000"（1.2 万赞 / 6.8 千藏）
5. "北漂 3 年，第 4 次搬家的避坑清单"（9.8 千赞 / 7.5 千藏）

**标题规律**：
- 最稳的结构 = **数字 + 反差**（"30㎡"+"住成家"，"押金一分没扣"+"退租"）
- 标题平均长度 14-18 字，含 emoji 1-2 个
- 含"押金"字样的笔记互动率比平均高 60%

## 5. 内容结构拆解

**呈现形式**：图文 73% / 视频 27%（视频均为改造过程实拍）

**开头钩子类型**：
- 数字冲击 38%（"4 次搬家、3000 押金、87 个差评…"）
- 反常识结论 24%（"租房比买房更适合精装修"）
- 身份共鸣 21%（"作为北漂第 4 年的独居女生…"）
- 问题提出 17%

**主体结构**（按笔记类型）：
- 改造类：现状（凌乱/老旧）→ 改造步骤（编号 3-5 步）→ 成品对比 → 成本清单
- 避坑类：数字冲击 → 踩坑案例 → 原因拆解 → 避坑清单
- 测评类：场景痛点 → 产品对比 → 个人选择 → 使用反馈

**结尾 CTA**：
- 资料诱饵占 52%（"评论'清单'发完整版"）
- 互动引导占 31%（"你们退租被扣过押金吗？"）
- 主页引导占 17%

**高频金句** Top 5：
1. "租的是房子，住的是生活"
2. "押金不扣，是租房人最大的体面"
3. "不打洞也能让出租屋有家的样子"
4. "搬家不是逃跑，是给生活换个版本"
5. "可带走的家具，比好看的家具更值"

## 6. 数据指标体检

| 指标 | 实测 | 评价 |
|------|------|------|
| 赞粉比 | 6.5 | 健康（理想 3-8）|
| 平均互动率 | 4.2% | 高于赛道均值 |
| 爆款率 | 22% | 优质对标号门槛达成 |
| 赞藏比 | 1.4 : 1（赞略多）| 平衡型，兼顾情绪 + 工具价值 |
| 赞评比 | 18 : 1 | 评论稍弱，可在评论区设钩子加强 |

**指标解读**：典型"工具型人设型混合号"，赞藏比例接近，说明内容既有情绪共鸣（爱看）又有工具价值（要存）——这种是最稳的腰部号画像。

## 7. 变现路径

- **主要变现**：种草（占商业笔记 80%）+ 软广（20%）
- **商业笔记密度**：每 10 篇中约 1 篇带 #广告 标签，密度低，保人设
- **典型产品类型**：免打孔置物架、便携家具、租房友好型小家电
- **典型转化钩子**："这套花了 X 元，链接放评论第一条"
- **种草结构**（高频模板）：转折式——"与其每次搬家扔家具，不如选这种可拆卸的"
- **私域引流**：评论资料诱饵 → 引导主页 → 主页置顶含 IP 名片（未发现微信导流，合规）

## 9. 可复用结论 ⭐

### 能抄什么（具体到操作）
1. **"数字 + 反差"标题公式**：把目标人群最想要的结果（"押金一分没扣"）+ 具体数字（"30㎡"、"3000"）组合。例：自己做职场赛道可写"裸辞那天，HR 都没扣我年终"。
2. **反差二分构图封面**：左右/上下分屏前后对比，已被验证为本赛道点击率最高的封面模板。
3. **资料诱饵评论 CTA**：51% 笔记用"评论 X 发清单"，这是积累私域 + 拉互动率的最稳套路。
4. **稳频低密度商业化**：每 10 篇 1 商单的密度让人设不崩，腰部博主可直接抄。

### 要避什么
1. **评论互动偏弱（赞评比 18:1）**：不要照搬其结尾 CTA 习惯，建议在评论区主动激起争议或追问。
2. **图文 73% 偏重**：现在视频流量权重在涨，新号可考虑图文+视频均衡。

### 3 条立刻可执行建议
1. **本周选题**：仿写"押金/退租"主题 1 篇，标题套用"数字 + 反差"公式。
2. **封面工具**：用 Canva / 醒图建一个"前后反差"封面模板，绑定固定字体 + 色块。
3. **评论区**：每篇笔记前 30 分钟内主动 3 条置顶争议性 + 资料钩子评论，弥补其评论弱项。

## 三、验收 checklist

成稿前对照以下 12 项自检，**任何一项打 ✗ 都需返工**：

### 数据完整性
- [ ] 表1（基础信息）字段全部填充，无空白
- [ ] Top 10 爆款笔记表填满（不足时降为 Top 5 并说明）
- [ ] 6 项数据指标（赞粉比/互动率/爆款率/赞藏比/赞评比/发文频率）均有数值

- [ ] 每个主章节末尾有一句"规律总结"

### 结构合规
- [ ] 报告章节顺序与"骨架"一致（1→9 + 附）
