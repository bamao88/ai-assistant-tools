# 执行、质量检查与维护

## 先绑定，再操作

按 [_local-chrome.md](_local-chrome.md)复用本机已打开Chrome，运行会话hook；账号判断按 [_accounts-and-sessions.md](_accounts-and-sessions.md)。所有平台使用同一已锁定Chrome入口，素材使用本机实际可读路径。不得连接另一台电脑、使用脚本独立profile或在掉线时自动恢复Cookie。

接管前`before_connect`、写入/上传前`before_upload`、最终提交前`before_submit`。hook失败即停止该动作并报告错误，不重建合同规避。通过仅证明输入的会话路由符合约束，平台身份、质量和权限仍须真实页面验收。

## 原页连续性

先接回已有任务页。上传/编辑出错时读当前状态，区分连接失效、字段没落地、平台处理未完成、素材失败及平台校验。多步调用部分失败时前面动作可能生效，核对后只补缺项；不刷新、重传或盲目重试提交。

未登录或错误账号时保留该Chrome原页，请用户在此登录。登录完成重新读身份与稿件状态；不运行check-login、导Cookie或另起认证浏览器。

正文替换只清目标编辑器，保留已确认空行。话题选择平台联想实体，只补缺失项，不因预览复制导致重复。封面要完成上传与保存，再逐个比例查看；封面评估分数不代替视觉检查。定时值失焦后再读，不能因为控件分钟粒度改动已接受稿。

## 最终提交前质量门

| 项目 | 真实检查依据 |
|---|---|
| 浏览器/账号 | 最新hook通过；同一Chrome/profile/tab；平台原生ID和昵称匹配目标 |
| 素材 | 文件正确；上传及平台处理已完成，没有失败/占位槽位 |
| 文案 | 与确认版本一致；正文分段可见，内部来源/备注不混入 |
| 话题 | 原生实体、数量和重复项；不是仅有普通井号字符串 |
| 封面 | 已保存；所有展示比例的文字、主体和边缘均可见 |
| 来源/声明 | 按授权使用独立字段；不擅自关联作者、笔记或活动 |
| 排期/可见性 | 完整日期、时区、实际读回值；不自动改立即发布 |
| 权限/查重 | 最新指令允许该动作；没有已接受稿或结果未知的先前尝试 |

记pass/fail/unverified/not-applicable与依据。缺项先原页修正；未检查不写通过。需要人审阅时在对话直接展示实际内容。保存草稿也需任务授权，不能因取消而自动保存。

## 回执和收尾

每个平台独立记录本机、浏览器/扩展绑定、profile证据、平台真实身份、tab、hook、字段检查、计划时间、提交权限、动作与回执。区分材料准备、上传、填好、待人审阅、已提交/已定时、公开可见；配置和成功退出码不代表业务完成。

结果未知先查原稿，禁止重投。保留未完成平台页，每轮重新markHandoff；只关闭本条成功发布的精确页，不关浏览器/窗口/其它任务。只读验证不上传、不填稿、不保存、不提交。

## 维护验收

发布期间遇控件异常先原页补救，用户明确维护后再改代码。只修改本次负责层与受影响调用方，避免复制临时脚本成新默认。说明改动做静态核对；hook做logic/contract；真实Chrome接管和平台登录分别记录；未重放上传/提交就不称发布E2E通过。
