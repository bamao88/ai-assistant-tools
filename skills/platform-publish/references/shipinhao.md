# 视频号发布：本机现有 Chrome

本 reference 处理微信视频号助手的视频发布。使用本台电脑中用户已经登录的日常 Chrome；先执行 [本机 Chrome 会话门](_local-chrome.md)，在 `before_connect`、`before_upload`、`before_submit` 核对同一任务锁定的浏览器及配置。发现脚本专用配置、另一台电脑或会话变化时由 hook 报错并停止。

不调用旧引擎的登录检查、扫码启动、Cookie 导入或发布命令，不新建配置，不修改浏览器凭据。平台原页要求扫码/微信确认时，请用户在同一 Chrome 里完成登录，保留现场后继续。

## 接管、身份与能力边界

1. 从当前浏览器清单绑定用户日常 Chrome 的真实配置，优先接回本条已有页面；新标签也必须属于同一配置。
2. 入口来自现有实现：视频号助手 `https://channels.weixin.qq.com/platform`；视频发布页 `https://channels.weixin.qq.com/platform/post/create`；稿件管理页 `https://channels.weixin.qq.com/platform/post/list`。实际页面跳转和菜单以本轮观察为准。
3. 核对目标视频号名称及可见的原生账号身份，与项目/本条账号映射一致。没有可靠目标时澄清，不借其它项目历史 slot 补位。
4. 打开管理页查本条已有稿件。仅验证接管时只看身份、入口和状态，不选文件、不填表、不存草稿、不发表；已提交作品不用于重复发布验证。
5. 当前工作流覆盖视频。视频号图文没有在本路径验证时，不把旧引擎骨架或其它平台图文能力说成已接入，也不擅自用视频替代用户所需图文。

## 发布包与字段

核对 `core_brief.md`、`publish_<account>.md`、已确认视频、封面和停止点，按 [素材规格](../assets/platform_rules.yaml) 校验。

- 短标题和描述是不同字段：短标题位于独立 input；描述/动态编辑区容纳完整标题、正文和话题。按发布包顺序保留标题、换行、分段正文、换行、标签，避免把短标题覆盖整段描述。
- 短标题按素材规格的 6–16 字准备，描述校验上限 1000；不要从其它平台的已压缩标题机械截取。实际控件限制须在页面核对。
- 视频号关键词使用本平台已确认的精简 5 项，逐个选择并确认真实话题；不把其它平台的全部关键词直接追加。
- 使用已确认自定义封面，检查视频号竖封面展示与文字安全区。不能把视频第一帧出现封面等同自定义封面已保存。

## 原页操作顺序

1. 上传本条视频，观察真实进度与解析状态。上传完成和封面可编辑是不同阶段；“生成中”“视频处理中，请等待完成后再编辑”等提示存在时保持原页等待。
2. 填写短标题、正式描述及原生话题，读回段落、空行和标签实体。来源/内部备注不自动拼入正文。
3. 等平台默认封面生成后再打开自定义封面上传，等待保存成功并在发表页核对最终缩略图。超时、保存失败或入口禁用时停止，不能带着默认封面提交。
4. 即时/定时按本次授权设置，失焦读回日期、时区、小时分钟。历史页面要求定时至少晚于当前 2 小时，实际有效范围以本轮控件提示为准；不复制旧测试日期。
5. 默认不声明原创。只有本条素材确认原创且已授权时才选择“声明原创”；该操作可能有第二层“原创权益”弹窗，需要阅读条款勾选并点击弹窗确认，再回到原页读回状态。转载不得沿用原创选择。
6. 原创入口可能在视频处理和其它字段完成后才出现或启用，按真实页面状态操作，不因早期找不到就另开环境或连续重试。

## 质量门、发表与收尾

按 [执行与质量](_execution-quality.md) 检查账号、视频完成状态、封面保存、短标题、分段描述、话题、来源/原创、可见范围及完整排期，保存视口、关键区域和字段证据。`before_submit` hook 必须仍通过同一浏览器绑定检查。

- 仅验证/填表或 `manual-submit`：保留当前页，不点“保存草稿”或“发表”。任务明确包含草稿时才保存，并核验实际草稿回执。
- 已获 `agent-submit` 且质量门通过：在同一页面独立点击发表/定时发表一次，沿用现有明确授权，不重复确认。
- 点击后未获确定回执时先去管理页查重；返回列表、审核中、定时待公开、实际公开分别记录，不能重复点击或重新上传。
- 成功后只关闭当前作品的任务发布页，保留其它未完成平台页与用户原标签；每轮为所有未完成页面更新保留标记。

旧 slot、CLI、Cookie 迁移和历史测试原文保存在 `history/shipinhao-legacy.md`，不再作为执行入口。旧引擎的上传或登录测试不证明当前 Chrome 接管或最终发表已通过，必须按真实操作说明验证层级。
