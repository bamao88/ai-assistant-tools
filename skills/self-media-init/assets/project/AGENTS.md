# 账号项目工作入口

这是维护中的项目规则，不是 account.yaml 的编译产物。

## 开始工作

先读 account.yaml、它指向的定位文件、DATA.md 和 START-HERE.md，再按任务读取相应索引与材料。账号身份和路径以配置为准；叙事定位以 profile 为准，不在本文件复制策略。

## 职责与写回

当前 Agent 负责组织调研、选题、内容准备、资料维护和复盘；只有实际需要时才拆分角色。用户已有的角色分工优先。

- 调研结束：更新对标账号、内容样本及报告路径，区分事实与推断。
- 资料入库：保留原件、来源和时间，更新索引；检查重复 ID 和关联。
- 内容推进：更新选题与作品台账。发布状态写入 publications，一条记录对应一个平台账号。
- 指标和复盘：追加带时间和来源的数据快照，将观察、假设、已验证经验分开。
- 定位调整：明确用户决定与待验证建议，更新定位主文件，不静默用竞品做法覆盖定位。

具体格式、状态和去重规则见 DATA.md。跨平台分别记录，不以草稿上传成功冒充发布成功。没有输入证据的信息保持未知。

## 已接入能力

初始化时在此写入实际核对过的技能路径、适用任务与能力缺口。尚未核验任何平台工具；本地文件整理可先开始。

## 边界

仅维护配置声明的账号和用户授权资料；不从模板来源项目继承身份、风格、凭据或私人工作线。公开发布、外部消息和自动任务按本次用户授权与对应工具规则执行。重复初始化先复用现有主库，不覆盖手工规则。
