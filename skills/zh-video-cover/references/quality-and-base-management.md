# 封面质量标准 + 底图管理（生成后必读必做）

生成器只按参数出图，**图好不好要 agent 自己看**。批量/单张跑完后，本文件的三件事是必做项，不是可选。

## 一、什么是一张好封面（质量标准 rubric）

对每张生成的封面，`Read` 图片逐条核：

1. **人脸在视觉中心**：脸大致落在画面上半的视觉重心，水平居中；**头顶留一点白但别太多**（大片空/贴顶都不行），脸不被切、不歪贴一侧。这是最常出问题的一项。
2. **脸和文字不打架**：底部渐变+文字压在下方约 1/4，不盖到脸/下巴；脸和字之间有呼吸感。
3. **字够大、手机不放大能读**：一图一事、两行字。`feedback_cover_diagram_mobile_first` 的手机优先原则。
4. **文字少→字号更大**：字号是宽度驱动的（短句本应自动放大到 132 封顶），但**要目视确认**短句真的顶大了、没有一行小字飘在中间留一堆空。若某条特别短还显小，检查是不是另一行太长把字号压下去了。
5. **底图和这一批别撞**：见第三节。

不达标就调（见第二节），别将就发。

## 二、生成后自检 + 调整流程（闭环，别一次跑完就完）

```
跑生成器 → Read 输出图(批量看 overview.png) → 按 rubric 逐张判 → 不合格的单张重出 → 再看 → 直到都达标
```

**最常见的调整：人脸高低（--lift）。** 默认上移 3/16（0.1875），但不同底图人物取景不同，按规则移完效果不一定好——**结合你实际看到的图调**：

- 脸偏低/贴底、下巴离字太近 → **加大 lift**（如 `--lift 0.25`、`0.28`），把人往上提到视觉中心。
- 脸贴顶/头发被切 → **减小 lift**（如 `--lift 0.125`）。
- 原则：调到**人脸在画面视觉中心、头顶留白适中**为止。

```bash
# 单张按图微调 lift 重出（覆盖 kit 默认）
"$PY" "$GEN" --title "第一行|第二行" --base frame-03 --lift 0.25 --output /abs/cover.png
```

其他调整：字太小/太挤 → 检查标题是否某行过长（换更短的候选标题）；底图不合适 → `--base` 换一张。
批量里想让某条固定用某 lift，在 manifest 该 item 加 `"lift": 0.25`。

> 经验值参考（本项目 kit 底图）：室外帧 3/16 合适；室内/人物取景偏高的帧可用 1/8。5/16 通常太高。

## 三、底图轮换纪律（批量必查）

底图 = 张和固定品牌人像，靠轮换、与内容无关。但**一批里同一张脸不能反复用**：

- 硬规则（已自动）：相邻发布不撞底图（`adjacent_collisions` 应为 `[]`）。
- **软规则（要你把关）**：同一底图在一批里**最多用 2 次**（kit `rotation.max_reuse_warn`）。批量输出的 `base_usage` 直方图 + `warnings` 会告诉你哪张超了。
- 超了怎么办：**优先补底图**（第四节）让池子够大；补不了就接受、但要清楚这批脸会重复，别再往上加更多同图。
- 例：本项目 5 张可用底图撑 13 条，必然有 3 张各用 3 次 → 批量会告警"至少再补 2 张"。这是真实约束，不是 bug。

## 四、底图不够怎么办（补充 + 抽帧经验）

**底图池位置**（与黑块黄字 kit 共用，单一真源）：
`tools/skills/platform-publish/assets/video-cover/zhanghe/covers/`
新的张和口播竖帧丢进去、排序后自动纳入轮换（除非加进 kit `rotation.exclude`）。

**当 `warnings` 报"池子太小"或你想要更多变化时，按这个顺序**：

1. **先翻现成人像底图库**：`assistant_zh/assets/video_cover_base/`（`INDEX.yaml` 机读，按源视频分子目录；竖版 9:16、未叠字、已人工筛）。有合适的直接 `cp` 进 `covers/`。
2. **没有就去媒体库找最近的张和口播视频抽帧**：媒体库在 `/Volumes/ExtSSD2601/media/`（git 树外，按拍摄分目录）。挑**张和正脸口播、竖版**的原片。
3. **抽帧走 find-images skill「方式三·视频帧截图」**，工具 `tools/engines/screenshot/video_frame.py`。抽帧后**人工/目视筛**，选帧标准：
   - 张和正脸、**不闭眼、口型自然**（别抓到说话糊脸的中间帧）；
   - 竖版 9:16、清晰、未叠字幕/未叠框架；
   - 构图允许"裁 3:4 + 上移"后脸仍在中心、头顶有余量（上下别顶死）；
   - 背景干净、光线正常。
4. 筛好的帧 → 命名 `frame-0X`（接着现有序号）→ 丢进 `covers/`。跑一张单张确认裁切/上移后脸位好，再纳入批量。

**如果你判断不了、或不确定该用哪条视频/哪帧 → 停下来反馈用户**（"底图只剩 N 张、这批要 M 条、需要补图，最近有 X 视频可抽帧，要不要抽？"），别硬凑重复底图발出。

> 注：`assets/video_cover_base/` 是"候选人像库"（可从中挑），`covers/` 是"skill 实际轮换池"（真正用的）。补图 = 从前者/抽帧选好 → 落进后者。本次 evc 首批的源帧残留在 `assistant_zh/tmp/video_cover_frames/final/`，也是一处可回收的候选。
