# 红队叙事公众号模板

这是用第二篇样例文章抽象出的“同等风格模板”。它复用的是排版语法，不复用原文、截图或账号品牌资产。

## 抽象结果

- 版心：白底窄栏，最大宽度 700px，左右 12px 内边距。
- 正文：16px，行高 1.85，段间距 18px，颜色 `#1a1a1a`。
- 标题：H2 使用红底白字条，20px，600 字重，圆角 4px。
- 强调：`strong` 使用红字加浅红底，适合句内关键判断。
- 图片：居中，最大高度 500px，红色 2px 描边，6px 圆角，轻红色阴影。
- 引用：浅红底加红色左边框，用于结论、风险或提醒。

## 文件

- `style-tokens.json`：抽象后的设计 token。
- `theme-snippet.ts`：可迁入 `gzh-publish` 的主题对象草案。
- `template.html`：公众号编辑器可用的内联 HTML 骨架。
- `preview.html`：本地浏览器预览。

## 使用建议

- 红色强调每 3 到 5 段出现一次即可，避免全文到处高亮。
- 每个 H2 后面先放结论或场景，再放解释。
- 图片优先放真实产品截图、流程图或操作结果，不放纯装饰图。
- 适合产品体验、工具评测、Agent 工作流、个人实测型长文。
