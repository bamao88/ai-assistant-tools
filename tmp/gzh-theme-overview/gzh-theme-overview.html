Agent 产品的下一步

一个可靠的 Agent 产品，必须先能解释自己为什么失败，再谈自动化。

•是否有稳定的 baseline，而不是只展示一次惊艳 demo

•是否能把人工判断沉淀成评估标准

•是否能在异常状态下给用户一个可恢复的出口
