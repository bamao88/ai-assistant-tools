# 技能不重要，主动性才是AI时代真正的护城河

你有没有想过，你花了多少时间学习"AI技能"——Prompt技巧、工具用法、工作流搭建——结果发现身边那些进展最快的人，他们根本就没在系统地"学"什么？

他们只是一直在动手。遇到问题就试，试了再看，看完再改。

最近我读到 Lenny's Newsletter 上的一期播客，采访对象是 Notion 的产品负责人 Max Schoening。这个人的履历有意思：Google 出来的 PM，在 Heroku 做过设计，在 GitHub 做到 VP of Design，同时还兼职工程师，两次创业。他现在带着 Notion 的设计师和产品经理直接在终端写代码、在 Claude Code 里做原型、把 Figma 稿子直接转成可运行的产品。

这场对话让我意识到，我一直有个认知误区：我以为 AI 时代最重要的事是掌握一套技能。Max 把这个认知彻底颠了——他说，真正能把人跟人拉开差距的，不是技能，是 agency（主动性/能动性）。

**技能 vs. 主动性：这两个词差在哪里**

听起来像文字游戏，但仔细想完全不是。

技能是"我会用 Claude Code"，主动性是"我遇到这个问题，我会主动想到用 Claude Code 去解决，然后我真的去做了"。前者是状态，后者是行为模式。

Max 在 Notion 内部推动设计师和 PM 写代码，他发现最大的阻力不是"不会写"，而是"没有动力去尝试"。会写和愿意写、敢写，是两回事。所以他们内部有个文化叫"drive it like it's stolen"——开一辆借来的车，你会格外珍惜地开，格外认真地对待每一个决策。这不是技术问题，是心态问题。

我在带训练营的时候也观察到同样的现象。学员中进步最快的那批人，不一定是技术背景最强的，也不一定是逻辑最缜密的。他们的共同特点是：听到一个新工具，当天就去装、去跑；遇到一个问题，不等别人给答案，先自己试；试出了什么东西，马上想着怎么延伸。

这种人在 AI 时代有天然的优势——不是因为他们天赋异禀，而是因为 AI 工具现在已经把执行成本压低到了极点。只要你有主动性，门槛几乎为零。

让我深思的是，这和我之前教大家"先学 eval，再学 prompt，再学 RAG"的技能路径其实并不矛盾，但优先级要重新排。技能路径是必要的，但如果一个人没有主动性，再好的课程也只是知识，不会变成行动力。

**Vibe Coding 造出更多软件，但没造出更好的软件**

Max 提出了一个非常犀利的观察：AI coding 工具让软件的数量爆炸了，但软件的质量并没有跟上。

这个观察让我有点不舒服——因为我自己有时候也是这个问题的参与者。

当你用 Claude Code 一天能推进十个想法的时候，很容易陷入一种"生产力幻觉"：你在疯狂输出，但输出的东西有多少真正解决了问题？有多少只是看起来能跑、但细节粗糙、边界情况一堆的东西？

Max 把这个问题归结为一个更深的设计哲学：每一个伟大的产品，核心都是一个极小的"tiny core"——一个单一的核心机制，做到极致，然后其他一切都围绕它展开。

他举了几个例子让我印象深刻。iPhone 的 multi-touch，一个手指触屏交互的核心设计，彻底重塑了移动设备的可能性。GitHub 的 Pull Request，把代码协作这件事变成了一个可审查、可讨论的社会化流程。Notion 的 blocks，把文档从线性结构解放出来，变成可以任意组合的积木。Dropbox 的菜单栏图标，让文件同步这件本来很复杂的事情，入口就是一个小角标。

这些"tiny core"有什么共同点？都不复杂，都可以用一句话说清楚，但都需要对用户行为有极深刻的理解，才能抓到那个真正关键的节点。

我认为这背后的逻辑其实很简单：AI 降低了"把东西做出来"的门槛，但没有降低"想清楚要做什么"的门槛。反而，因为执行变容易了，"想清楚"这件事的权重被放大了。以前你花一个月做出来的东西，发现方向不对，损失很大。现在你花三天就能做出来，发现方向不对，损失小多了——但你可以把这个优势浪费在"做了很多没方向的东西"上，也可以把它用在"快速验证方向"上。

两种人的差距，还是那个词：agency。

**软件的"数量爆炸"正在创造反向机会**

既然软件数量在爆炸、质量在下滑，那这个缺口里就藏着机会。

Max 对所谓"SaaSpocalypse"（SaaS 末日论）持保留态度。他不认为 AI 会杀死 SaaS，但他认为 AI 会淘汰那些没有真正"tiny core"的产品——那些只是把一堆功能拼在一起、没有核心差异化机制的工具。

这和我一直在讲的判断是吻合的。我一直认为，AI 时代的产品机会不是"谁用 AI 把功能做得更全"，而是"谁真正理解某一类用户的核心需求，然后用 AI 把这个场景做到极致"。大模型降低了工程成本，但提高了产品判断的价值。

Jevons 悖论在这里特别适用：当某件事的成本降低时，人们的需求不会减少，反而会增加。软件的生产成本降了，但好软件的稀缺性反而提高了——因为烂软件更多了，好软件就更稀罕，用户也更挑剔。

这个场景我太熟悉了。训练营里学员做产品，最常见的问题不是做不出来，而是做了一堆没有焦点的东西。功能很多，每个功能都差不多够用，但就是找不到那个让用户会主动推荐给朋友的核心价值点。这不是 AI 的问题，这是产品判断的问题，也是 Max 说的 tiny core 缺失的问题。

**"每个项目的前10%现在是免费的"意味着什么**

Max 提到一个判断：AI 让每个项目的前 10% 几乎变成了"免费"——你可以快速起步、快速探索、快速看到一个雏形，几乎没有成本。

这个判断让我想起一件事。我一直在推的"先 build、先跑起来"逻辑，背后的道理其实正在被工具加速验证。以前你要做一个东西，光是环境搭建、基础框架就要花好几天，这个成本让很多"值得试一试"的想法死在了门口。现在不一样了，一个下午可以让一个原型跑起来。

但这里有一个反直觉的推论：如果前 10% 是免费的，那为什么还有那么多人迟迟不启动？

我认为原因还是主动性的问题。"免费"这件事本身不会自动触发行动。你得先有那个"我要去试试这件事"的冲动，才能利用上工具带来的低成本。

比这更有意思的是，当前 10% 变免费之后，后 90% 的挑战并没有消失——稳定性、用户体验、边界情况的处理、真正难的架构决策——这些都还在。所以那些只把 AI 当作"快速出活"工具的人，很快会遇到天花板。而那些把 AI 当作"快速验证判断"工具的人，才能持续推进。

**为什么设计师和 PM 在终端写代码，是一个正确的方向**

Max 的一个实践让我觉得非常有示范意义：他让 Notion 的设计师和 PM 直接用 Claude Code 把 Figma 稿子转成可运行的代码，在真实环境里看效果。

这不只是效率问题，更是认知问题。

一个设计稿和一个真实运行的界面，感受完全不一样。前者你在评估视觉，后者你在感受交互。一个设计师如果从来不在真实环境里验证自己的设计，他永远有一层和现实的隔阂。而当他能在几分钟内把稿子跑起来看，他的判断会变得更准确，迭代会更快，和工程师的沟通也会更有质量。

我之前讲过，大模型时代技术界限变模糊了——算法工程师、工程师、产品经理、设计师之间的边界在淡化。这不是说大家都要变成全栈工程师，而是说每个人都可以在自己的判断范围内推进更多东西，不再需要在每个小决策上等别人。

这个变化非常关键。传统软件开发里，PM 写需求文档，设计师出稿，工程师实现，三个角色之间的信息损耗巨大。每次交接都会有东西丢失。而当 PM 和设计师能直接产出可运行的原型，交接的信息量大幅下降，协作效率大幅提升。

Max 把这件事做成了 Notion 的内部文化，我认为这是一个值得在更多团队里推广的方向。不是每个设计师都要变成工程师，但每个设计师都应该能在工具的帮助下，把自己的想法快速变成可以感受到的东西。

**我的思考：主动性是一种可以被培育的东西，而不是天生的**

Max 这场访谈里最让我印象深刻的判断，是他说 agency 是可以被培育的，不是有些人天生有、有些人天生没有。

这个观点击中了要害。

很多人把"我不够主动"当成性格问题，觉得这是很难改变的东西。但 Max 的实践说明，环境和工具可以极大地影响一个人的主动性。当你发现"去试试看"的成本极低，你就更容易去试。当你试了之后发现真的有反馈有进展，你就更容易再试一次。这是一个可以被正向强化的循环。

往更大的图景里看，我觉得这个时代正在发生一件非常深刻的结构性变化：人和想法之间的距离被压缩了。

工业时代，一个人有想法，要把它变成现实，需要资本、工人、机器、漫长的生产周期。互联网时代，这个距离被压缩了一些——有代码技能的人可以以极低的边际成本复制软件，但"会写代码"本身还是一个相当高的门槛。现在，这个门槛几乎消失了。你有想法，有主动性，AI 工具就是你的执行层。

这和 PC 时代让文字创作民主化、互联网让信息传播民主化是一条脉络上的延伸。但这一次，被民主化的是"创造"本身——不只是传播、不只是记录，而是真正意义上的构建新事物的能力。

在这种环境里，技能会持续折旧——今天学的工具，明年可能就被更好的工具替代。但主动性不会折旧。一个持续有主动性的人，会在每一波新工具出来的时候第一批上手，会在每一次行业变化里第一批找到新的方向。

说实话，这个认知对我自己也是一个提醒。我有时候会过度聚焦在"教大家学什么技能"这件事上，但技能是手段，行动力才是目的。一个学了一百个技能但从不动手的人，和一个只会几个工具但天天在做东西的人，后者的成长速度会快得多。

AI 浪潮才刚刚进入实质性的应用阶段，未来几年会有更多的工具出来，更多的可能性被打开。能持续利用上这些机会的人，不是掌握了最多技能的人，而是主动性最强的那批人。

这场变革才刚刚开始，而你现在站在哪里，很大程度上取决于你愿不愿意动起来。

也欢迎大家留言讨论，你在日常工作中是怎么培养自己的主动性的？
