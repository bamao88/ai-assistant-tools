## Viewpoint Core
张和的核心立场：豆包手机助手这类 OS Agent 真正动的是"操作权"，不是某个功能。操作权一旦从 App 手里转到 OS 手里，移动互联网十年攒下的分发、交易、流量生态位会被重新洗牌——App 从"入口"被降级成"可被调用的服务"，这是一次生态位重排，不是一次功能升级。

## Boundaries
- 张和没有断言"App 会死/会消失"，他的判断是 App 被"管道化"、价值收缩到底层内容和供应商协议，界面价值消失，不是公司消失。
