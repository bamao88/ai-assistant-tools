## Viewpoint Core
张和的原始立场：**AI PM 最重要的能力是产品判断力——具体落到"选对方向 + 评测/数据驱动 + 黑客级竞品调研 + 技术判断"这套体系认知。工具（Claude Code 等）是必须立刻上手的"时代标配"和进入 build 模式的载体，但它是手段，不是核心能力本身。** 张和明确说过"核心能力不是掌握某项技术"。

## Boundaries
- 张和**从未**说过"产品判断不重要"或"掌握热门工具比产品判断更重要"。
- 张和强调"立刻换最强工具"，指的是**不要被差工具拖累效率**，不等于"掌握工具是 AI PM 最重要的能力"。
- 不能把"工具必选 + 拥抱新工具"这条方法论，偷换成"工具熟练度 > 产品判断"这个能力排序结论。两者方向相反。

## Depth Gap
此题不存在"补素材就能写"的深度缺口——缺的不是机制/数据/案例，而是**张和根本不持有用户要求的那个立场**。补再多外部研究也只能加深张和"产品判断为核心"的判断，不能反转成"工具熟练度为核心"。
